## 模型设置页：每个 ComfyUI 工作流可独立测试

「ComfyUI 模型」在本项目 = `imageWorkflowLib` / `videoWorkflowLib` 中的工作流库条目（`kind` 只有 image/video），不是 checkpoint 名。原先只有「▶ 测试全部」，现补上逐条独立测试。

### 架构决策
- 后端把 `test-batch` 主体抽成模块级共享函数 `executeLibraryTests()`（`src/api/routes/comfy.mjs`），新增 `POST /api/comfyui/test-one {kind, id, prompt?}`；两个端点行为（连接探测 / 串行 runWorkflow / 每项即时写回 lastTest / SSE `wf-test` 日志）完全一致，`test-batch` 原契约不变。
- 单项接口额外返回 `result` 详情：`promptId`、产物 URL 列表、`applied` 数、提示词注入计划（positive/negative/warnings），前端据此渲染缩略图与注入位置。
- 前端 `public/panels.js` 的 `testBatch(kind, ids, {single})` 同时服务单项与批量；`testBusy` 忙锁保证同一时刻只有一个试跑任务（避免抢 ComfyUI 队列 / 串日志），期间禁用两个「测试全部」按钮。
- 加固：连接探测加 `AbortSignal.timeout(8000)`（地址被代理吞掉时不再无限转圈）；客户端断开导致的取消不再写成 `lastTest` 失败，保留该行原状态。
