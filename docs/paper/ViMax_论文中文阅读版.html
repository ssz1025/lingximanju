0. 一分钟速览

一句话：ViMax 不训练新的视频生成模型，而是用一套多智能体「制片流水线」，把闭源的 LLM／图像／视频模型编排起来，让它们协作产出多镜头、跨场景仍连贯的叙事视频。

它的两个敌人：

敌人 表现 ViMax 的解法
长程叙事规划 几十上百个镜头一起规划，超出 LLM 推理容量；局部决策脱离全局故事 层次化分解（事件 → 场景 → 镜头）+ RAG 检索原著补全全局上下文
跨镜头视觉一致性 每个镜头独立生成，角色长相、道具、房间布局逐镜漂移 机位依赖图 + 视觉锚点传播（对象一致）；转场视频作空间锚点（几何一致）；VLM best-of-k 择优（质量兜底）

三个最该记住的数字：

  • GC 0.5272 → 0.5571：ViMax 相对最强非智能体基线 HoloCine 的全局一致性提升（绝对值 +0.0299，约 +5.7%）。
  • 405 秒 / 17.5 美元：一个 8–16 镜头故事的端到端时延与 API 成本（best-of-2 默认配置）。
  • NF 3.52 / 5：小说转分镜的「忠于原著」得分，虽为全场最高，但离满分仍远——忠实度依然是开放问题。

定位判断：这是一篇系统与框架论文（orchestration framework），核心贡献是把已有能力（RAG、依赖图、VLM 评审、并行调度）组合成一条可跑的长视频流水线，并配了基准 ViMax-Bench；不是提出新的生成模型或新的训练算法。读它时，重点看「编排逻辑」和「消融证据」，不必期待模型结构创新。

1. 论文要填的空白

作者把现有工作归为三类，逐一切中点：

路线 代表 能做到 缺什么
文生视频大模型 Sora、Veo 3、Seedance、Wan、HunyuanVideo 单镜头画质高 只有数秒；拉长后角色身份、世界几何、物理规律漂移
流式 / 一致性机制 StreamingT2V、FreeLong；StoryDiffusion、ConsiStory、STAGE 延长单片段，或保住主体身份 前者不能做多场景叙事，后者没有叙事规划
多智能体制片 FilmAgent、Kubrick、VideoGen-of-Thought、MovieAgent、AniMaker 拆分导演/编剧等角色 无法同时协调叙事、视觉、时序三类约束，跨几十镜头时全局连贯崩掉

于是作者把问题收敛为两个挑战：多镜头视觉一致性（对象级 + 空间级）与长程叙事规划。全文方法章节就是这两个挑战的逐条应答。

2. 方法全景：一条流水线 + 三根支柱

主线（第 2.1 节，式 1–4）：

创意 I（几句话 / 小说 / 剧本）
  → ① 编剧 ScreenWriting：按输入类别路由提示词，生成统一格式剧本 S
  → ② 镜头规划 ShotPlanning：分镜智能体输出每镜头的机位、运镜、光照、走位、时长
  → ③ 关键帧 ImageGen：角色定妆照 / 场景图 / 镜头首帧（文生图 + 参考图生图）
  → ④ 视频生成 VideoGen：以「镜头规格 + 关键帧」为条件逐镜头出片
  → ⑤ VLM 质量控制：每个任务并行采样 k 个候选，VLM 打分择优（best-of-k）

支柱一：层次化叙事规划（2.2，式 5–6）。故事按「主要事件 → 场景 → 镜头」递归分解，让 LLM 每层只处理合适粒度的任务；但分解会丢掉原著里的角色动机、伏笔等细节，因此再对完整原著建索引，用每个节点的描述去检索相关上下文并「增强」描述（RAG）。分解管复杂度，RAG 管信息不丢失——这是理解第 2.2 节的关键分工。

支柱二：基于图的视觉依赖（2.3.1，式 7）。规划阶段把镜头分配给「机位」，构建机位依赖图；生成阶段按拓扑序执行：无依赖的机位分支并行生成，有依赖的机位则继承前驱节点传播下来的视觉锚点。这个设计一箭双雕——既保证角色/道具一致，又天然给出可并行的调度图（第 3.5 节的效率收益来自这里）。

支柱三：转场视频作空间锚点（2.3.2，式 8）。同一场景换个机位拍，最容易穿帮的是三维布局。ViMax 不独立生成每个视角，而是先生成一段从机位 A 平滑移动到机位 B 的转场视频，再从视频里抽取两端视角——借用视频模型自身的时空一致性来「锁定」房间布局，隐式满足 180 度轴线规则。

一句话记法：RAG 借原文的记忆力，依赖图借已生成镜头的视觉记忆，转场视频借视频模型的空间记忆。

3. 三项贡献的「含金量」

  1. 多智能体长视频框架：工程整合度最高的一项。价值在于把编剧、分镜、造型、生成、质检拆成可替换模块，且依赖图暴露并行性。
  2. 层次化 + RAG 的叙事规划：思路经典，但用在「小说 → 上百镜头分镜」上有针对性；消融也确实显示 RAG 主要提升 NF（3.14 → 3.52）。
  3. 双层视觉一致性：机位依赖图 + 转场视频是最有辨识度的设计；消融中「去掉全部跨镜头依赖」使总体 GC 掉 8.7%，是全文最有力的因果证据。

另外别漏了第四项实质贡献：ViMax-Bench（附录 A.1–A.2），35 个故事、438 个镜头、按一致性类型（角色持久性 / 背景持久性 / 多人交互）× 长度（中篇 2 场 8–10 镜 / 长篇 3–4 场 12–16 镜）组织，是本文可复用的评测资产。

4. 实验速查

先弄清指标，否则数字会被误读：CC / IC / GC 不是人工评分，也不是「一致率」，而是用 ViCLIP 把每个镜头编码成视频级特征后，对同一故事内镜头对求余弦相似度——IC 只算同场景内镜头对，CC 只算跨场景镜头对，GC 算全部。它衡量的是特征稳定性，是视觉一致性的代理指标（见附录 A.2）。叙事规划指标（CBC/NC/PPR/VSU/STQ/NF）才是 GPT-5.4 按 1–5 量表打的分。

7. 批判性阅读清单（带问号的地方）

  1. 「长视频」的实际尺度有限。基准只有 35 个故事、每个 2–4 场景 / 8–16 镜头、共 438 个镜头，本质是「多镜头短片」；结论能否外推到分钟级、小时级、数百镜头，论文没有证明（作者在局限性第 2 点也承认规模有限）。
  2. GC 只是代理指标。ViCLIP 余弦相似度偏爱整体风格稳定，不必然等于「角色是同一个人」；0.5571 与 0.5272 的差距约 0.03，绝对值都不高。人类评估（表 2）与定性案例（附录 A.6）才是对它的必要补充。
  3. 忠实原著仍是短板。NF 最高仅 3.52/5；「小说 → 分镜」在 50 部小说上评测，但只取前 20 / 前 100 张分镜分组打分，长程衰减曲线并未报告。
  4. best-of-3 反而变差被解释为「候选增多带来选择噪声」，也可能说明 VLM 评审器判别力已饱和；论文未做评审器与人类偏好的一致性校验。
  5. 成本与闭源依赖。每个故事约 17.5 美元 API 费用、405 秒；全链路依赖 Gemini / GPT / Claude / Veo / Wan 等模型，作者明确承认性能对模型版本更新敏感，复现结果可能随时间漂移。
  6. 基线适配的公平性。MovieAgent、AniMaker 被换成与 ViMax 相同的图像/视频骨干，但保留各自原生规划；这控制了生成骨干变量，却也可能放大规划模块差异，读表 1 时需留意方法名里的骨干标注。
  7. 误差会级联。作者自述：关键帧生成器在人群密集、接触频繁场景表现差；视频生成器有时不遵循关键帧语义（角色从跑步机上跑开）；一旦关键帧出错，会被后续镜头当作参考继续传播——这也解释了为什么 VLM 择优能带来 3.8% 的 GC 收益。
  8. 作者自己指出的方向性风险：商业视频模型在短时程多镜头一致性上进步很快，未来编排框架的价值可能转向「跨场景的长时程视觉记忆管理」，而非重复造底座已有的能力（局限性第 4 点）。此外音频、对白同步、镜头节奏、交互式修订都尚未覆盖。

9. 带走这一句

ViMax 的核心不是「生成得更好」，而是把长片制作中原本靠人维护的三份记忆——故事上下文、已生成镜头的视觉状态、场景的三维几何——显式地建模成可检索、可传播、可并行调度的数据结构，再用 VLM 在关键帧阶段做质量闸门。

摘要

长视频生成需要系统性的叙事规划与视觉一致性，而现有的短片段生成方法无法提供这些能力。现有方法生成的是彼此孤立、缺乏叙事结构的镜头序列，也没有机制在跨场景时维持角色外观与环境的一致性。我们提出 ViMax——一个智能体化（agentic）的视频生成框架，通过多个专职组件协同协作、共同协商叙事决策、视觉连续性与成片质量来完成视频创作。该框架采用带检索增强生成（RAG）的层次化叙事引擎以保证全局故事连贯，并引入依赖感知的视觉一致性机制，跨时间边界追踪角色与环境状态；同时，由视觉语言模型（VLM）引导的智能体持续监控并优化叙事连贯性与视觉保真度。借助这种协同协作，框架能够生成长篇叙事内容，在多场景时间线上同时保持故事的完整性与视觉的连贯性。ViMax 的代码开源于：https://github.com/HKUDS/ViMax。

1 引言

当前的视频生成方法存在关键局限：只能产出没有叙事结构的短片段，且角色外观与环境元素在跨场景时会发生不可预测的变化。生成式 AI 近期的突破为应对这些根本性挑战带来了变革性潜力：通过智能体化框架自动化复杂的视频制作流水线，创作者得以以前所未有的便利，把概念性的创意转化为连贯的长篇视觉叙事。

视频生成的近期研究已从多个方向尝试应对这些挑战。以 Sora（OpenAI, 2024）、Veo 3（Google DeepMind, 2024）、Seedance（Team Seedance et al., 2026）为代表的文生视频模型，以及 HunyuanVideo（Kong et al., 2024）、Wan（Team Wan, 2025）等开源工作，已在单镜头保真度上取得令人印象深刻的效果。然而，这些模型仍局限于仅持续数秒的短内容。一旦扩展到更长的时程，它们会出现灾难性的语义遗忘：角色身份、世界几何结构与物理规律在镜头之间不可预测地漂移（Kupyn et al., 2025；Rakheja et al., 2025），从而破坏叙事沉浸感。

已有两条技术路线试图解决时序一致性问题，但都存在明显局限。流式生成方法（StreamingT2V，Henschel et al., 2025；FreeLong，Lu et al., 2024）延长了单个片段的时长，却无法处理多场景叙事。一致性机制（StoryDiffusion，Zhou et al., 2024；ConsiStory，Tewel et al., 2024；STAGE，Zhang et al., 2025b）通过共享注意力或关键帧锚定来保持主体身份，却缺乏叙事规划能力。多智能体框架（FilmAgent，Xu et al., 2025；Kubrick，He et al., 2024；VideoGen-of-Thought，Zheng et al., 2024）虽然把制作流程拆分为专职角色，却无法协同协调叙事、视觉与时序这三类复杂约束。既有系统都难以在长篇叙事所必需的数十个镜头之间维持全局连贯。

要突破这些局限，必须克服两项根本挑战：

  • 多镜头视觉一致性。现有视频生成器在彼此隔离的镜头上工作，不感知此前已生成的内容，导致角色外观、环境设计与空间布局发生漂移。长片制作既需要对象级一致性以保持角色与环境属性，也需要空间连贯性以在不同机位下维持一致的三维几何关系。

  • 长程叙事规划。编排横跨数十个镜头的叙事，若作为单一任务整体处理，会超出当前语言模型的推理容量。系统需要在协调角色弧光、情节推进与主题连贯的同时，让每一项局部决策都扎根于更宏观的故事上下文。

为应对上述挑战，我们提出 ViMax：一个从概念创意到完整渲染成片、统筹长视频制作的智能体框架。ViMax 把这条流水线拆解为负责编剧、镜头规划、角色造型、视频生成以及基于 VLM 的质量控制（best-of-$k$ 择优）的专职智能体，由它们协同维持全流程的连贯性。

针对叙事复杂性，ViMax 采用层次化故事分解 + 检索增强生成，使局部规划始终以全局上下文为依据；针对视觉一致性，ViMax 引入基于图的依赖系统，在规划阶段追踪跨镜头关系，并通过转场视频生成维持同一场景内不同机位之间的空间连贯。

本文的主要贡献包括：

  • 智能体化的长视频生成框架。提出一种多智能体架构，协同编剧、镜头规划、角色造型、视频生成与基于 VLM 的质量控制，实现从概念创意出发的叙事视频自动创作。

  • 具备全局上下文的层次化叙事规划。提出层次化故事分解并与检索增强生成相结合，使语言模型能够在长篇叙事中保持主题连贯与长程依赖。

  • 基于图的视觉一致性。通过双层机制解决视觉一致性：基于图的依赖追踪保证对象一致性，转场视频生成保证空间连贯。

2 方法

2.1 长视频生成工作流

为生成长视频，ViMax 采用一套复杂的多智能体工作流，以应对长篇叙事内容创作固有的复杂性。与短视频生成不同，长片制作需要在叙事结构、角色一致性、电影摄影设计与质量控制等多个维度上协同。我们的工作流覆盖导演意图、编剧、镜头规划、角色造型、视频生成与质量评估等关键制作角色，由各专职智能体协作维持整个生产流水线的连贯性。

2.1.1 从创意到视频

编剧（Screenwriting）。用户首先用自然语言陈述创作想法。这一输入 $\mathcal{I}$ 可以是多种叙事形态：既可能是几句话描述的高层创作意图（例如「一位侦探在小镇上破解一桩疑案」），也可能是完整的小说，或已有的剧本草稿。

为确定视频的故事线，ViMax 首先把用户输入 $\mathcal{I}$ 投影为统一格式的剧本：

$$ \mathcal{S}=\text{ScreenWriting}(\mathcal{I};P_{C(\mathcal{I})}) \tag{1} $$

其中 $\text{ScreenWriting}(\cdot)$ 是基于大语言模型（LLM）的编剧方法，依据用户输入 $\mathcal{I}$ 撰写高质量剧本。该过程由面向不同输入类别定制的提示词 $P_{C(\mathcal{I})}$ 驱动，并通过分类机制 $C(\cdot)$ 把用户输入路由到合适的视频创作类别。生成的剧本 $\mathcal{S}$ 提供场景描述、角色对白与叙事推进等结构化基础，指导后续所有制作阶段。

镜头规划（Shot Planning）。为确定传达故事所需的恰当电影语言与视觉表达，ViMax 随后由分镜智能体（storyboard agent）执行镜头规划。该智能体由精心设计的提示词驱动，其中封装了专业电影摄影知识与镜头设计原则，按结构化序列给出每个镜头的视觉内容、音效与对白的详细描述。形式化地：

$$ S_{1},S_{2},\cdots,S_{n}=\text{ShotPlanning}(\mathcal{S}) \tag{2} $$

其中 $S_{1},S_{2},\cdots,S_{n}$ 表示为完成视频叙事而规划的镜头序列，$\text{ShotPlanning}(\cdot)$ 是把剧本 $\mathcal{S}$ 转换为细粒度镜头规格的 LLM 函数。每个镜头 $S_i$ 都包含机位角度、运镜、光照条件、人物走位、时长等完整制作细节，为后续视频生成提供技术蓝图。

文—图—视频生成（Text-Image-Video Generation）。为更好地控制生成过程，ViMax 采用两步式的「文生图 → 图生视频」流程：先生成关键图像，如角色定妆照、场景背景图与镜头关键帧；这一步既包含文生图，也包含「文本 + 参考图」生图，因为镜头关键帧等图像需要以角色图等为参考。随后利用「文本 + 图像」生视频工具逐镜头生成视频。形式化地：

$$ \{\mathcal{K}_{1},\mathcal{K}_{2},\cdots,\mathcal{K}_{m}\}=\text{ImageGen}(\{S\}) $$
$$ \{V_{1},V_{2},\cdots,V_{n}\}=\text{VideoGen}(\{S\},\{\mathcal{K}\}) \tag{3} $$

其中 $\{\mathcal{K}_{1},\cdots,\mathcal{K}_{m}\}$ 是生成的关键图像集合（含角色设计与场景参考图），$\{V_{1},\cdots,V_{n}\}$ 是对应各规划镜头的最终视频片段。通过显式规定关键图像内容、并在中间视觉阶段实施质量控制，ViMax 加强了对最终成片的把控。

2.1.2 基于 VLM 的质量控制

为保证生成质量，ViMax 采用基于 VLM 的评估机制执行 best-of-$k$ 候选择优：对每个任务并行采样 $k$ 个候选，由 VLM 评审器依据镜头规划要求，在视觉保真度、叙事一致性、镜头规格遵循度等维度上打分，得分最高者进入流水线：

$$ \{C_{1},C_{2},\cdots,C_{k}\}=\text{MultiGen}(S_{i},\text{prompt}) $$
$$ \text{score}_{j}=\text{VLM-Judge}(C_{j},S_{i}) $$
$$ C^{*}=\arg\max_{C_{j}}\text{score}_{j} \tag{4} $$

其中 $\{C_1,\cdots,C_k\}$ 为采样的 $k$ 个候选，$\text{VLM-Judge}(\cdot)$ 依据镜头要求 $S_i$ 为每个候选打分，$C^{*}$ 为选出的最优候选。该选择机制缓解了单次生成的方差，确保只有最贴合规格的输出才会进入长片流水线，避免不合格的关键帧在后续镜头中被当作参考而放大误差。

2.2 长程叙事规划

长程叙事规划是一项根本性挑战：在延展的时间线上协调多个故事要素，其复杂度呈指数级增长。与短内容不同，长视频需要联合编排横跨数百个场景的角色弧光、情节推进与叙事连贯。若把这一切当作单一规划任务，信息规模会大幅超出当前语言模型的推理容量；而要在局部场景之间维持全局一致性，又会在「精细控制」与「整体连贯」之间形成张力。

2.2.1 层次化故事分解

为应对长视频规划内在的结构复杂性，ViMax 采用层次化故事分解。长视频包含数百乃至数千个镜头，且天然具有清晰的层次结构：多个镜头可以共同构成一个动作段落或一次对话交锋；同一空间内发生的镜头，在光照、人物走位、环境一致性上存在强视觉依赖。这种嵌套结构使「直接在镜头粒度上规划」在计算上不可行，也容易产生前后矛盾。

我们的层次化分解通过递归拆分，把完整故事线系统地切分为可管理的规划单元：从完整剧本出发，先识别代表重要叙事里程碑的主要故事事件；再把每个事件拆分为若干场景，每个场景对应具体戏剧时刻或地点转换；最后把场景细化为镜头规格，定义机位角度、角色动作与视觉元素。该递归过程形式化为：

$$ {N_{d,1},N_{d,2},\cdots,N_{d,k_{d}}}=\text{Decomp}(N_{d-1,i}) \tag{5} $$

其中 $N_{d-1,i}$ 是深度 $d-1$ 上的父节点，$\{N_{d,1},\cdots,N_{d,k_d}\}$ 是它在深度 $d$ 上的子节点，每个节点 $N_{d,j}$ 都关联一段文本化叙事描述 $T_{d,j}$。这一方法保证语言模型在每一层只处理范围适当的规划任务，既避免同时做多尺度叙事设计带来的「认知过载」，又保留了故事要素之间天然的层次依赖。

2.2.2 基于 RAG 的全局上下文感知

层次化分解虽能有效管理复杂度，却带来一个关键缺陷：各节点生成的描述主要着眼于界定该叙事单元的范围与边界，而非提供丰富细致的内容描述。于是，原始素材中的宝贵上下文信息——角色动机、微妙的情节关联、主题元素——往往在分解过程中被丢弃。为此，ViMax 采用检索增强生成（RAG），在整个规划流程中保持对全局上下文的感知。

系统在规划流水线开始前，先对完整剧本或小说内容建立综合索引，再依据分解阶段生成的文本描述动态检索相关上下文；对每个叙事节点，查询索引中的原始素材，用相关全局信息充实局部规划：

$$ \mathcal{R}=\text{Index}(\mathcal{S}),\quad C_{d,j}=\text{Retrieve}(\mathcal{R},T_{d,j}) $$
$$ T^{\prime}_{d,j}=\text{Enrich}(T_{d,j},C_{d,j}) \tag{6} $$

其中 $\mathcal{R}$ 为原始素材的索引表示，$C_{d,j}$ 是与节点描述 $T_{d,j}$ 相关的检索上下文，$T'_{d,j}$ 是同时融合局部规划细节与全局叙事语境的增强描述。索引与检索组件构成一套完整的 RAG 系统：通过把局部规划决策锚定在更广阔的故事上下文中，避免前后矛盾，并在整个长视频制作中维持主题连贯。

2.3 跨镜头的视觉一致性

多镜头视频生成的一个根本挑战，来自各镜头生成过程彼此独立：每次生成都不感知此前已生成的内容，导致角色外观、环境设定、道具与空间关系出现不一致。在长视频中，长镜头序列上的视觉连贯对叙事沉浸感与观感连续性至关重要，这种隔离性因而尤为致命。为此，ViMax 提出两套互补方案，在保持生成效率的同时确保视觉连贯。

2.3.1 基于图的视觉依赖

为保证跨镜头视觉一致性，ViMax 建立了一套依赖驱动的生成框架，通过「机位级依赖图」维护镜头间的视觉依赖。例如，出现同一批常驻角色的镜头、或从不同机位拍摄同一环境的镜头，都存在必须随时间保持的视觉依赖；同一场景内多次出现的车辆、建筑等物体，也需要协同生成以维持外观一致。

该方法分两阶段运作：依赖检测与依赖感知生成。规划阶段，系统分析一个场景内所有镜头的文本描述，把镜头分配给不同机位，并构建刻画其视觉关系的机位依赖图；生成阶段，系统按该图的拓扑序执行：依赖已满足的机位可并行生成，而存在依赖的机位会吸收从前驱节点传播而来的视觉锚点（visual anchor）：

$$ \mathcal{G}=\operatorname{BuildCameraGraph}\left(\{S_{i}\}_{i=1}^{n}\right) $$
$$ \mathcal{K}_{i}=\operatorname{GenConditioned}\left(S_{i},A_{i}\right) \tag{7} $$

其中 $n$ 为当前场景的镜头数，$i$ 为镜头索引；$\mathcal{G}$ 是由 $\operatorname{BuildCameraGraph}(\cdot)$ 依据镜头规格构建的机位依赖图，其节点与边分别表示机位及机位间的视觉依赖；$S_i$、$\mathcal{K}_i$ 分别为镜头 $i$ 的规格与生成的关键帧，$A_i$ 是该镜头所属机位的视觉锚点，按 $\mathcal{G}$ 传播；$\operatorname{GenConditioned}(\cdot)$ 表示以镜头规格与对应视觉锚点为条件的参考图生图。该做法既维持了跨镜头视觉一致性，又通过推理时并行处理相互独立的机位分支，把生成效率最大化。

2.3.2 通过转场视频实现空间连贯

为处理场景内部的空间一致性，ViMax 利用转场视频生成保证同一物理空间内多机位之间的几何连贯。当多个镜头从不同视角拍摄同一场景时，维持空间关系对避免相互矛盾的三维布局至关重要。例如两人对坐的对话场景：分别聚焦两位角色的独立镜头，必须保持一致的相对站位、家具摆放与环境几何，才能维系「同一物理空间」的观感。

我们的方案利用视频生成模型内在的空间一致性能力：不独立生成每个视角，而是先识别需要空间连贯的场景，再生成把不同机位视角连接起来的平滑运镜转场。这些转场视频充当空间锚点，确保同一场景内所有视角共享一致的三维几何。例如为对话中的两位角色分别生成镜头时，系统先生成一段把机位从角色 A 的角度平滑移动到角色 B 的角度的转场视频，为两个独立镜头建立统一的空间基础：

$$ V_{trans}=\text{GenTransition}(C_{i},C_{j},S) $$
$$ V_{i},V_{j}=\text{ExtractViews}(V_{trans},C_{i},C_{j}) \tag{8} $$

其中 $V_{trans}$ 是场景 $S$ 内机位 $C_i$ 与 $C_j$ 之间的转场视频，$V_i$、$V_j$ 是从该转场视频中在对应机位角度抽取的、空间一致的视角。通过借用视频生成模型内部的时空一致性机制，该做法在实践中消除了多视角间相互矛盾的三维布局，同时在镜头之间保持自然的运镜过渡。

4 相关工作

层次化叙事规划与电影逻辑。长故事连贯性此前主要通过层次化分解解决：Plan-And-Write（Yao et al., 2018）把故事线规划与表层实现分离；DOME（Wang et al., 2024）引入动态提纲与记忆以避免剧情漏洞。在视频规划方向，VideoDirectorGPT（Lin et al., 2023）通过符号规划把角色动作锚定到跨镜头；FilMaster（Huang et al., 2025）检索镜头语言以实现行业级节奏；Chu et al.（2025）用动态实体关系图缓解持续的叙事碎片化。

面向内容创作的多智能体框架。视频制作天然适合清晰、高度结构化的智能体分工。Generative Agents（Park et al., 2023）展示了可信的长期行为；MAViS（Wang et al., 2025）用「探索—检视—增强」循环协调角色；GenMAC（Huang et al., 2024a）通过「设计—生成—再设计」循环迭代纠正组合性错误；StoryAgent（Hu et al., 2024）以中间表示桥接抽象意图与像素级生成；MovieAgent（Wu et al., 2025）模拟导演与编剧角色以组织结构、场景与摄影。

长视频生成与视觉一致性。长时程生成必须克服持续的身份与风格漂移。VideoAuteur（Xiao et al., 2025）采用滚动上下文策略，MovieDreamer（Zhao et al., 2024）通过自回归全局规划预测视觉 token。在时序视觉连贯方向，StableAnimator（Tu et al., 2025）把人脸嵌入与时序层对齐以抑制身份退化，Identity-GRPO（Meng et al., 2025a）用 RLHF 对抗多人视频中的身份漂移；SEINE（Chen et al., 2023）以掩码扩散桥接独立镜头，EvalCrafter（Liu et al., 2024）为一致性、运动与美学质量提供了系统的评测指标。

5 结论

我们提出了 ViMax——一个通过多智能体协同工作流实现长视频生成的框架。它以层次化故事分解 + 检索增强生成应对叙事规划，以基于图的依赖追踪 + 转场视频生成保证视觉一致性；依赖图同时暴露出镜头级并行性，使大规模生成更高效。我们还引入了 ViMax-Bench，一个面向受控跨镜头一致性挑战的综合基准。通过把制作过程拆解为专职智能体，ViMax 使连贯长篇叙事的可扩展创作成为可能，为娱乐、教育与媒体生产领域的自动化内容创作开辟了新的可能。展望未来，我们把 ViMax 视为迈向「完全智能体化电影制作」的一步：在能力日益强大的基础模型之上，可以叠加更丰富的多模态生成、长时程记忆与交互式共创，让自动化影像创作更接近实用部署。

局限性

尽管 ViMax 改善了长程规划与视觉一致性，仍存在若干局限：

  1. 依赖闭源基础模型。系统在推理、关键帧与视频生成、以及基于 VLM 的质量控制上都依赖专有基础模型，性能因而对模型版本更新敏感。

  2. 自动评测的粒度不足。自动评估依赖基于表征相似度的指标，虽可扩展，却难以刻画细粒度叙事意图与语义复杂案例（多人交互、解剖学瑕疵、导演级电影逻辑）；ViMax-Bench 同样只面向规模有限的受控挑战。

  3. 生成组件仍脆弱。关键帧生成器在人物密集、接触频繁的场景中表现不佳；视频生成器也不总遵循关键帧语义（例如角色本应站在跑步机上，却被动画化为跑离跑步机），且误差会沿流水线级联放大。

  4. 基础模型能力上移带来的定位变化。近期商业视频模型已在短时程多镜头一致性上展现可观能力，这提示未来的编排框架应更多转向跨场景的长时程视觉记忆管理，而非重复实现更强的底座模型可能原生具备的能力。

  5. 尚不覆盖音频与交互。当前工作流尚未处理音频、对白同步、镜头级节奏控制，也不支持交互式修订。

伦理考量

ViMax 支持长视频生产，但更强的跨镜头一致性也会放大滥用风险，如冒充他人、伪造事件、模仿受版权保护的角色。部署时应要求取得同意、提供来源溯源或水印，并对敏感案例保留人工审核。ViMax-Bench 设置了安全约束，可缓解基准层面的风险，但无法覆盖更广泛的滥用；此外，基于 LLM 与 VLM 的评审器可能继承其底座模型或影视素材中的偏见，因而给出的是「可扩展但不完美」的评价信号。

A.2 数据与评测协议

我们构建 ViMax-Bench，用于在受控的一致性挑战下评估长篇「叙事转视频」生成。该基准包含 35 个多镜头故事规格，由图 11 所示提示词经 GPT-5.2 生成，每个故事跨 2–4 个场景、8–16 个镜头。每个镜头都被写成独立分镜面板，包含首帧描述与运动提示词，以鼓励「硬切多镜头生成」，而非连续长镜头合成。基准设计参考了 StoryMem（Zhang et al., 2025a）与 VideoMemory（Zhou et al., 2026）研究的多镜头叙事设定与一致性挑战。

ViMax-Bench 面向以电影镜头设计为基础的硬切多镜头叙事生成：规格中纳入过肩镜头、反打镜头、插入镜头及多样构图等摄影技法，同时要求在场景切换后仍有常驻角色复现，并在大幅视角变化下保持空间一致。这一设计，为研究 ViMax 所针对的跨镜头叙事与视觉一致性挑战提供了受控环境。

基准沿两个互补维度组织。其一是受压力的一致性类型：(i) 角色持久性（A 类），考察在不同环境、光照与构图下的身份保持；(ii) 背景持久性（B 类），考察复杂室内场景中的几何与空间稳定性；(iii) 多人交互（C 类），考察多个视觉上可区分的角色在共同动作中是否仍彼此可分。其二是叙事长度：中篇故事含 2 个场景、8–10 个镜头，长篇故事含 3–4 个场景、12–16 个镜头。该划分同时增加时间跨度与场景级复杂度，便于分析不同叙事尺度下的一致性。

自动一致性指标

我们沿用 HoloCine（Meng et al., 2025b）与 StoryMem 的跨镜头一致性协议，用 ViCLIP（Wang et al., 2023）度量镜头级相似度：把每个生成的镜头编码为一个视频级特征，对同一故事内的每一对镜头计算余弦相似度。IC 对同一场景内的镜头对取平均，CC 对跨场景的镜头对取平均，GC 对全部镜头对取平均。「角色持久性 / 背景持久性 / 多人交互」这些情景标签只用于界定每个故事所覆盖的挑战类型，并非人工打分，也不要求专家标注。三个指标均为自动指标，数值越高表示特征越稳定。

人类评估协议

评估覆盖全部 35 个 ViMax-Bench 故事、438 个生成镜头。每个故事把 ViMax 与五个基线比较，得到 $35\times 5=175$ 个唯一比较对。每一对中，ViMax 视频与基线视频匿名并排呈现，左右位置随机化以降低位置偏差。共有 15 位具备 AI 相关背景的评审者参与：我们构造 15 个均衡标注桶，每桶含全部 35 个故事、且对每个基线有 7 次比较，每桶分配给一位评审者。每个唯一比较对出现在 3 个桶中，因而由 3 位评审者独立判定，共计 $175\times 3=525$ 次成对判断。

评审者按三项标准选出更偏好的完整视频：(i) 跨场景一致性（CSC），覆盖跨镜头与跨场景的常驻角色、物体、服装、身份特征、视觉风格以及动作／行为特征；(ii) 语义遵循（SF），覆盖所描绘的主体、动作、交互、环境与叙事推进；(iii) 美学质量（AQ），覆盖画面质量、构图、视觉吸引力与电影化呈现。人类研究在视觉连续性之外直接评估语义执行与整体呈现，补充了 CC/IC/GC 的不足。

为保证比较单元对齐，我们采用「20 张分镜」评分协议：由于基线并非为一次性端到端产出长程分镜而设计，只评估其前 20 张子分镜；对端到端生成长程分镜的 ViMax，则取前 100 张子分镜，按每 20 张连续分为五组，在相同协议下独立打分并取平均。该设计既保持每批次评估单元一致，又能体现长程规划能力。

A.3 基线细节

评估遵循 StoryMem 与 HoloCine 的联合协议，ViMax-Bench 提示词由 GPT-5.2 适配到各基线的原生输入格式。共使用七个视频生成基线，覆盖 (i) 独立调用并拼接的镜头级文生视频模型；(ii) 把运动生成交给 Wan2.2-I2V-A14B 的关键帧锚定流水线；(iii) 统一式多镜头生成；(iv) 智能体化视频生成框架。所有方法接收相同的 35 个底层故事与镜头要求；各基线按其标准生成流程运行，不使用 ViMax 专有的参考传播、转场生成或后处理。另有三个叙事规划基线，按附录 A.2 的对齐协议单独评估。

镜头级文生视频生成器

  • Wan2.2-T2V-A14B（Team Wan, 2025）：领先的开源扩散 Transformer 视频基础模型，在数十亿图像与视频上训练，镜头级文生视频能力强。
  • Veo 3.1（Google DeepMind, 2024）：代表性商业系统，支持文生视频、图生视频与音频感知生成，物理真实感强。

关键帧锚定的多镜头流水线

  • StoryDiffusion（Zhou et al., 2024）：以零样本「一致自注意力」实现跨图像主体一致，并配以语义运动预测器把关键帧动画化为平滑的长程视频。
  • IC-LoRA（Huang et al., 2024b）：上下文 LoRA 流水线，把多张图像拼接并联合描述，以轻量任务微调激活文生图 DiT 潜在的多图生成能力。

端到端多镜头视频生成器

  • HoloCine（Meng et al., 2025b）：整体式多镜头生成器，用窗口交叉注意力把提示词绑定到单个镜头，并以稀疏镜头间自注意力高效合成分钟级、叙事连贯的场景。

智能体化视频生成框架

  • MovieAgent（Wu et al., 2025）：多智能体电影生成框架，在剧本与角色库上执行层次化思维链规划，由 LLM 智能体扮演导演、编剧、分镜师与场景经理，组织场景、机位与摄影。
  • AniMaker（Shi et al., 2025）：多智能体叙事动画框架，仅凭文本生成全局一致的多镜头视频，结合 MCTS 启发的多候选片段生成与上下文感知的多镜头评估器做故事连贯择优。

A.4 实现细节

我们用一套统一的多智能体工作流实例化 ViMax，贯穿所有实验。Gemini-3-Flash 作为（视觉）语言骨干，承担编剧、层次化故事分解、镜头规划、视觉依赖分析与基于 VLM 的质量控制；在质量控制阶段，VLM 评审器通过联合评估视觉保真度、叙事一致性与对规划镜头规格的遵循度，从多个生成候选中择优。视觉合成方面，关键帧由 Gemini-3-Pro-Image 或 Gemini-3.1-Flash-Image 生成，镜头级视频生成与用于空间连贯的转场视频生成均由 Wan2.2 与 Veo 3.1 完成。

在叙事规划评估中，我们进一步为小说转视频流水线加入 RAG 增强的上下文锚定：用 GPT-5.4 做长程叙事规划、text-embedding-3-small 做文本嵌入、Qwen3-Rerank 做重排序。对关键帧锚定的多镜头流水线，先把 ViMax-Bench 的首帧提示词送入关键帧生成器，再把视频提示词交给动画器合成片段；对 ViMax 及其余基线，则把两个提示词拼接为单一输入一并提交。叙事规划评估中，所有对比方法的 LLM 骨干统一固定为 GPT-5.4。

视觉一致性与身份保持

长视频生成的一种关键失效模式是时空不一致：角色身份与环境细节在长时间跨度上漂移。ViMax 通过参考条件生成与基于图的视觉依赖追踪显式应对，以下为实证。

角色身份。图 9 显示 ViMax 在不连续镜头与剧烈机位变化之间保持主角身份：在「沙漠—飞船」片段（上两行），同一对男女主角在建立全景、驾驶舱双人镜头、沙暴光线下侧脸、紧凑的情绪特写之间均可辨认，即使光照从暖色夕阳转为冷绿色舱内照明，面部结构、发型与服装仍保持一致。「成长」片段（下两行）构成更严苛的检验：身份不仅需跨场景保持，还要跨童年、少年、青年、成年四个年龄阶段（故事内时间跨度约二十年）延续，同时金毛犬也从幼犬同步「变老」至老年犬。

空间连贯。图 8 突出 ViMax 在激进视角变化下维持全局一致场景几何的能力。在五镜头的警局讯问段落中——双人全景、对嫌疑人的过肩镜头、对警探的反打过肩、俯拍录音笔与记事本的插入镜头、反应特写——房间布局、两人相对座位、桌面道具与墙面陈设均保持几何一致，在反打镜头间隐式满足了 180 度轴线规则。图 9 把这一点扩展到更复杂的空间情境：河流野生动物片段中水上／水下的连续过渡、赛车片段中驾驶舱—赛道旁—航拍的视角切换、水下空间站片段中狭窄的内部走廊，都以一致的环境布局呈现。这种连贯源自转场视频生成模块：它作为非相邻镜头之间的空间锚点，避免机位重定位时出现相互矛盾的布局。

叙事逻辑与节奏

除视觉一致性外，生成内容的逻辑推进同样关键。ViMax 借助层次化叙事规划把高层创意分解为具备镜头级电影意图的连贯剧本。图 9、图 10 中的序列体现出专业的镜头语法：建立全景过渡到中景、再到反应特写；插入镜头被安放在有叙事意义的节拍上（如图 8 的录音笔、图 9 的驾驶舱仪表盘）；情绪高潮留给紧凑构图。这说明 ViMax 产出的不只是视觉一致的画面，而是节奏与镜头设计都体现有意为之的电影化叙事的序列。
