# 自然童话 · 宫崎骏清新美学

> 技能 id：`miyazaki` ｜ 分组：导演风格 ｜ 适用：奇幻动画、自然题材、成长故事、治愈系短片
> 落地代码：`src/core/director-styles.mjs` · `src/core/director-skills.mjs`

## 1. 目标、输入与交付

**解决什么问题**：画面甜得发腻、自然只是贴图、飞行没有重量、角色缺少生活感。以宫崎骏的自然观察与飞行浪漫为基准，输出干净、可信、有温度的动画世界。

**输入**

- 核心创意（一句话灵感或剧情描述）
- 主色调：晴空青（默认）｜ 森林绿 ｜ 黄昏橙 ｜ 雨雾灰
- 节奏类型：慢节奏生活流 / 中节奏冒险（默认慢节奏生活流）
- 运镜倾向：固定全景 + 缓移 / 飞行跟拍（默认固定全景 + 缓移）
- 总时长（默认 30 秒）
- 是否提供参考图

**交付**：16:9 成片；角色服装、道具（飞行器、背包）、场景地标跨镜一致；自然元素（云、风、草木）必须真实可感。

## 2. 项目结构规划

- **关键元素分组**：角色（身份板含服装、发型、随身道具）、场景（草坡、森林、天空、海边小镇、机械工房）、道具（飞行器、风车、提灯、面包）、载具（飞行器、蒸汽火车）。
- **序列**：按成片顺序，每镜一个生产单元；节拍按"日常 — 起飞 — 回望"的叙事顺序书写。
- **资产与素材**：身份板与场景板为基准；视频资产承载镜头结果。
- **剪辑**：以呼吸节奏剪辑，允许长镜内完成起飞或降落；结尾用缓慢拉远收束。

## 3. AGENTS.md 策略

- **交付规格**：16:9，默认 30 秒；台词极少，以画面与音乐叙事。
- **视觉方向**：干净清透的色彩、明确的光源（阳光穿透树叶）、手绘质感的纹理（水彩边缘、纸质颗粒）；人物有生活细节（汗、脏手、卷起的袖子）；天空必须有层次（云的高度、云的形状）。
- **节奏与转场**：慢节奏生活流（单镜 5–8 秒），冒险段中节奏（3–6 秒）；转场以直切与飞行连贯镜头为主。
- **模型配置**：身份板与场景板图像生成（风格串强调手绘动画质感）；分镜视频运动平滑，飞行段允许大幅位移。
- **身份板布局**：角色板 16:9，浅米背景，主视觉（全身含服装与随身道具）+ 表情研究（3 个）+ 手部与道具细节 + 服装版型示意。
- **连戏约束**：同一段飞行、同一场日常标同一连戏分组；继承状态只记角色位置与朝向、飞行器状态（螺旋桨转速、高度）、道具（背包是否背着）。

## 4. 创作流程规划

1. 锁定全局参数（主色 / 节奏 / 运镜 / 时长）。
2. 生成镜头结构（关键元素 + 分镜 + 音频层）。
3. 生成并确认关键元素参考资产。
4. 逐镜生成视频（强制绑定身份板与飞行器）。
5. 生成音频层（环境音 + 钢琴 / 管弦 BGM，BGM 权重高）。
6. 剪辑合成。

**依赖顺序**：2→1；3→2；4→3；5→2；6→3,4,5。

**何时暂停**：参数摘要、分镜清单、参考资产、音频层四处确认。

**异常与重试**

- **画面发甜**：降低粉色与高光溢出，加强环境细节（尘土、树皮、旧金属），否定词追加 `candy colors, plastic 3D render, overexposed`。
- **飞行没重量**：写出高度、风向、机身倾斜角、螺旋桨气流，重新生成。
- **人物漂移**：补绑身份板重试，最多 2 次。

## 5. 专业创作方法

**参考图分析**：人物提取年龄感、服装版型（背带、短裤、围裙）、发型、随身道具；场景提取地形轮廓、光源方向（阳光穿透角度）、植被类型与密度。

**角色关键元素**：外貌 + 服装版型 + 发型 + 随身道具 + 情绪标签（好奇 / 坚定 / 温柔）。身份板四区块：主视觉、表情研究、手部与道具、服装版型。

**场景关键元素**：空间类型（草坡 / 森林 / 天空 / 小镇）、光源方向与时段、植被与地标、常驻媒介（风、云、光斑、雨）。场景板含主视觉 + 光影研究（清晨 / 正午 / 黄昏）+ 材质细节（草叶、木纹、旧金属）+ 构图框架示意。

**分镜列表**

- 慢节奏 5–8 秒，冒险段 3–6 秒。
- 每镜写：场景、故事节拍（奔跑、起飞、落地、回望）、景别与构图（远景给环境、中景给人物关系、特写给手与道具）、镜头运动（固定全景 / 缓移 / 飞行跟拍）、媒介（风、云、光斑、雨）、光影（阳光穿透 / 黄昏逆光）、微表情（眼神、嘴角、手上的脏污）。
- 自然环境必须是"活的"：云在移动、草在摇、光斑在变。

**跨镜连续性**：同一段飞行标同一连戏分组；继承高度、朝向、飞行器状态、道具。特写需给出 2 个连续性证据（螺旋桨气流、机翼倾斜、背包带位置、地面参照物）。

**音频层**：环境音（风声、鸟鸣、机械声、水声）+ BGM（钢琴与管弦，旋律性强）。

## 6. 宫崎骏专属视觉语法

| 维度 | 取值 |
|---|---|
| 主色调 | 晴空青 `#7FB6D9` + 草绿 `#8FB35A` / 森林绿 `#3E6B4F` / 黄昏橙 `#E4A15C` |
| 色彩策略 | 清透高明度，阴影带蓝紫而非纯灰；色彩饱和但不刺眼 |
| 光线 | 阳光穿透树叶的斑驳光、黄昏逆光、云层散射 |
| 构图 | 大景别环境 + 人物偏置、天空占画面 1/3 以上、纵深用景深层次 |
| 运镜 | 固定全景、缓移、飞行跟拍、缓慢拉远 |
| 质感 | 手绘水彩边缘、纸质颗粒、植被细节、机械旧化 |
| 禁忌 | 糖果色、塑料 3D 感、过曝、无细节的自然贴图 |

**提示词骨架**

```
主体 + 生活化动作 + 环境大景别（草坡/森林/天空）+ 阳光穿透方向与光斑
+ 手绘动画质感（水彩边缘/纸颗粒）+ 活的自然（云移/草摇）+ 16:9
```

**固定否定词**：`candy colors, plastic 3D render, overexposed, flat cartoon shading, oversaturated pink, no texture background`
