# 静默暴烈 · 北野武极简美学

> 技能 id：`kitano` ｜ 分组：导演风格 ｜ 适用：黑帮题材、犯罪悬疑、沉默人物、极简叙事短片
> 落地代码：`src/core/director-styles.mjs` · `src/core/director-skills.mjs`

## 1. 目标、输入与交付

**解决什么问题**：暴力拍成动作片、沉默演成呆滞、构图随意、节奏靠配乐硬撑。以北野武的极简构型与静默暴力为基准，输出冷、准、狠的影像。

**输入**

- 核心创意（一句话灵感或剧情描述）
- 主色调：冷灰蓝（默认）｜ 夜黑 ｜ 海边青 ｜ 血红
- 节奏类型：极慢静默 / 骤然爆发（默认极慢静默 + 骤然爆发）
- 运镜倾向：固定机位 / 突然的静止与切（默认固定机位）
- 总时长（默认 30 秒）
- 是否提供参考图

**交付**：16:9 成片；角色服装、伤痕、道具（枪、刀、车）跨镜一致；暴力不做美化。

## 2. 项目结构规划

- **关键元素分组**：角色（身份板含西装 / 帮派服饰、伤痕、沉默表情）、场景（海边、车内、空旷仓库、夜街、天台）、道具（枪、刀、电话、烟）、载具（轿车、摩托车）。
- **序列**：按成片顺序，每镜一个生产单元；节拍按"沉默 — 压迫 — 突然爆发"的叙事顺序书写。
- **资产与素材**：身份板与场景板为基准；视频资产承载镜头结果。
- **剪辑**：长时间静止后突然剪辑；爆发用短促硬切；结尾常以静止画面或空镜结束。

## 3. AGENTS.md 策略

- **交付规格**：16:9，默认 30 秒；台词极少，允许沉默与短句。
- **视觉方向**：低饱和冷调、正面平视构图、居中对称、背景干净；光线平淡但精确（不是大平光，是有方向的平淡）；暴力必须突然、简短、无慢镜头美化。
- **节奏与转场**：极慢静默（单镜 8–12 秒，几乎不动）与爆发（0.5–2 秒硬切）交替；转场以硬切为主；禁止渐变、叠化、花式转场。
- **模型配置**：身份板与场景板图像生成；分镜视频运动极低，爆发段可用突然位移。
- **身份板布局**：角色板 16:9，浅灰背景，主视觉（全身正面，西装或帮派服饰）+ 正面表情研究（3 个，全部克制）+ 伤痕与道具细节 + 轮廓剪影。
- **连戏约束**：同一场对峙、同一次爆发标同一连戏分组；继承状态只记站位与朝向、枪械弹数、伤痕、车辆位置。

## 4. 创作流程规划

1. 锁定全局参数（主色 / 节奏 / 运镜 / 时长）。
2. 生成镜头结构（关键元素 + 分镜 + 音频层）。
3. 生成并确认关键元素参考资产。
4. 逐镜生成视频（强制绑定身份板）。
5. 生成音频层（环境音极简，BGM 克制或缺失）。
6. 剪辑合成（静止与爆发的节奏对比）。

**依赖顺序**：2→1；3→2；4→3；5→2；6→3,4,5。

**何时暂停**：参数摘要、分镜清单、参考资产、音频层四处确认。

**异常与重试**

- **暴力被美化**：去掉慢动作与英雄光效，改为突然、简短、画面外的暴力；否定词追加 `slow motion violence, heroic pose, glamorized blood`。
- **沉默变呆滞**：给角色明确的内心动作（等待、计算、忍耐），在微表情里写出来。
- **人物漂移**：补绑身份板重试，最多 2 次。

## 5. 专业创作方法

**参考图分析**：人物提取服装（西装版型、衬衫领口、帮派纹身）、伤痕位置、发型；场景提取空间开阔度、背景干净程度、光线方向。

**角色关键元素**：外貌 + 服装 + 伤痕 + 沉默时的姿态 + 情绪标签（压抑 / 冷静 / 突然的空）。身份板四区块：主视觉、正面表情、伤痕与道具、轮廓剪影。

**场景关键元素**：空间类型、背景干净程度（北野武式留白）、光线方向与平淡程度、标志性构件（车门、仓库门、海边防波堤）、常驻媒介（海风、雨、热浪）。场景板含主视觉 + 光影研究 + 材质细节 + 构图框架示意（居中对称轴线）。

**分镜列表**

- 静默 8–12 秒，爆发 0.5–2 秒。
- 每镜写：场景、故事节拍（等待、对视、掏枪、转身）、景别与构图（中景正面、全身居中、极简背景）、镜头运动（固定 / 突然的静止）、媒介（海风、雨、热浪扭曲）、光影（平淡但有方向的侧光）、微表情（眨眼频率、下颌、手指）。
- 暴力在画面外或极短呈现；不美化、不延展。

**跨镜连续性**：整场对峙标同一连戏分组；继承站位、朝向、枪械、伤痕、车辆。爆发后的特写需给出 2 个连续性证据（弹壳位置、衣物破损、血迹方向、车门开合角度）。

**音频层**：环境音（海浪、引擎、脚步、静默）+ BGM 可缺失或极简（单音、鼓点）。

## 6. 北野武专属视觉语法

| 维度 | 取值 |
|---|---|
| 主色调 | 冷灰蓝 `#5C6B78` + 白 `#E6E9EC` / 夜黑 `#131518` / 海边青 `#5E8A8C` |
| 色彩策略 | 低饱和冷调、背景干净、单点红（血）极少量 |
| 光线 | 有方向的平淡侧光；不打戏剧光，不铺柔光 |
| 构图 | 正面平视、居中对称、极简背景、大量留白（空的空间） |
| 运镜 | 固定机位；突然静止；不做运动镜头 |
| 质感 | 真实西装面料、皮肤纹理、海风与热浪的空气感 |
| 禁忌 | 暴力美化、慢镜英雄化、花式转场、做作表演 |

**提示词骨架**

```
主体正面居中 + 极简干净背景 + 有方向的平淡侧光 + 低饱和冷调
+ 真实面料与皮肤纹理 + 空气感（海风/热浪）+ 16:9
```

**固定否定词**：`slow motion violence, heroic pose, glamorized blood, dramatic lighting, flashy transition, oversaturated color`
