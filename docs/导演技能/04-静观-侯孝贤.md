# 静观 · 侯孝贤长镜美学

> 技能 id：`hou-hsiao-hsien` ｜ 分组：导演风格 ｜ 适用：乡土记忆、成长叙事、时代变迁、散文电影
> 落地代码：`src/core/director-styles.mjs` · `src/core/director-skills.mjs`

## 1. 目标、输入与交付

**解决什么问题**：镜头切得太碎、观众被喂情绪、空间关系混乱、生活质感假。以侯孝贤的固定长镜与"让时间自己说话"为基准，输出有呼吸感的散文电影。

**输入**

- 核心创意（一句话灵感或剧情描述）
- 主色调：远山青（默认）｜ 稻田黄绿 ｜ 老屋褐 ｜ 夜灯橙
- 节奏类型：极慢长镜 / 慢节奏静观（默认极慢长镜）
- 运镜倾向：固定机位 / 缓慢横移或后拉（默认固定机位）
- 总时长（默认 30 秒）
- 是否提供参考图

**交付**：16:9 成片；同一场景的光线时段、人物位置、道具状态连续；不靠台词解释。

## 2. 项目结构规划

- **关键元素分组**：角色（身份板含年龄变化、日常服装、走路姿态）、场景（庭院、稻田、车站、老屋、山道）、道具（单车、饭桌、火车票、风扇）、载具（火车、单车、机车）。
- **序列**：按成片顺序，每镜一个生产单元；节拍以"日常 — 变故 — 余韵"的叙事顺序书写。
- **资产与素材**：身份板与场景板为跨镜基准；视频资产承载镜头结果。
- **剪辑**：以直切为主，允许镜头内完成时间跨越；结尾允许长镜头自然收束。

## 3. AGENTS.md 策略

- **交付规格**：16:9，默认 30 秒；无旁白，台词极少且生活化。
- **视觉方向**：自然光、低饱和、真实生活质感（搪瓷碗、竹椅、旧墙斑驳、汗湿的衣领）；画面保留环境全貌，不做过度特写。
- **节奏与转场**：极慢长镜（单镜 8–12 秒），固定机位占比 ≥ 80%；镜头间默认直切；允许在镜头内通过人物进出完成转场；严禁快速剪辑与花式转场。
- **模型配置**：身份板与场景板图像生成；分镜视频运动强度极低，优先固定机位。
- **身份板布局**：角色板 16:9，米色背景，主视觉（全身，日常服装）+ 轮廓研究（2 个剪影）+ 表情研究（3 个，含一次背影或侧影）+ 姿态细节（走路、坐下、端碗）。
- **连戏约束**：同一场日常、同一段路程标同一连戏分组；继承状态只记人物在画面中的位置、光线时段、道具（单车是否在画面内、碗是否已空）。

## 4. 创作流程规划

1. 锁定全局参数（主色 / 节奏 / 运镜 / 时长）。
2. 生成镜头结构（关键元素 + 分镜 + 音频层）。
3. 生成并确认关键元素参考资产。
4. 逐镜生成视频（强制绑定身份板，固定机位优先）。
5. 生成音频层（环境音为主，BGM 可选且极简）。
6. 剪辑合成。

**依赖顺序**：2→1；3→2；4→3；5→2；6→3,4,5。

**何时暂停**：参数摘要、分镜清单、参考资产、音频层四处确认。

**异常与重试**

- **镜头太"演"**：把动作改成日常动作（端碗、推门、走神），否定词追加 `dramatic staging, theatrical performance`。
- **空间混乱**：在场景板锁定标志性构件（窗、门、树、电线杆）位置后重生成。
- **人物漂移**：补绑身份板重试，最多 2 次。

## 5. 专业创作方法

**参考图分析**：人物提取年龄感、日常服装质感（洗旧的棉布、褪色衬衫）、走路姿态；场景提取自然光时段、空间纵深、标志性构件（老树、电线杆、田埂）。

**角色关键元素**：外貌 + 日常服装 + 姿态习惯（坐姿、走路节奏、手的放置）+ 情绪标签（沉默 / 忍耐 / 忽然的松动）。身份板四区块：主视觉、轮廓研究、表情研究、姿态细节。

**场景关键元素**：空间类型、光线时段（清晨 / 正午 / 黄昏 / 夜）、标志性固定构件、常驻媒介（风、蝉鸣对应的视觉化元素如扬尘、树影摇动）。场景板含主视觉 + 光影研究 + 材质细节（墙面斑驳、竹椅纹理）+ 构图框架示意。

**分镜列表**

- 极慢 8–12 秒，慢节奏 6–10 秒。固定机位为主，允许一个镜内极缓后拉。
- 每镜写：场景、故事节拍（推门、端碗、坐下、望向窗外）、景别与构图（全景 / 远景为主，人物常偏置）、镜头运动（固定 / 极缓后拉）、媒介（风、树影、扬尘）、光影（自然光时段明确）、微表情（眼神停留、手指抠碗沿、肩膀下沉）。
- 禁止抽象情绪词，用生活动作与身体状态替代。

**跨镜连续性**：同一段路程（走出院子 → 田埂 → 车站）标同一连戏分组，继承人物位置、光线时段推进、道具与载具状态。

**音频层**：环境音为主（蝉鸣、远处火车、风扇转动、碗筷声）；BGM 可省略或只用环境化的弦乐。

## 6. 侯孝贤专属视觉语法

| 维度 | 取值 |
|---|---|
| 主色调 | 远山青 `#6E8577` + 雾白 `#E4E1D6` / 稻田黄绿 `#A7B05B` / 老屋褐 `#8A6B52` |
| 色彩策略 | 低饱和自然色，光影随时段变化而非靠色块 |
| 光线 | 自然光为主（窗光、天光、夕照），保留高光溢出与水汽感 |
| 构图 | 大景别、人物偏置、留出环境；纵深用田埂 / 廊道 / 山道引导 |
| 运镜 | 固定长镜；极缓后拉或横移；不用变焦 |
| 质感 | 生活器物、旧墙斑驳、汗湿衣领、灰尘与阳光颗粒 |
| 禁忌 | 快速剪辑、花式转场、舞台化表演、过度特写、糖水调色 |

**提示词骨架**

```
人物日常动作 + 环境全貌（大景别/偏置构图）+ 自然光时段与方向
+ 生活器物细节（搪瓷/竹椅/旧墙）+ 低饱和自然色 + 纵深引导线 + 16:9
```

**固定否定词**：`fast cutting, flashy transition, dramatic staging, theatrical performance, oversaturated, beauty filter, tight closeup montage`
