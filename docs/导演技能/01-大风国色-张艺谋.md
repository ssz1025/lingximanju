# 大风国色 · 张艺谋电影美学

> 技能 id：`zhangyimou` ｜ 分组：导演风格 ｜ 适用：国风武侠、历史史诗短片、高端国潮广告
> 落地代码：`src/core/director-styles.mjs`（美学档案）· `src/core/director-skills.mjs`（技能声明）

## 1. 目标、输入与交付

**解决什么问题**：画面廉价、角色频繁换脸、光影没有质感、色彩像糖水片。以张艺谋的色彩统治力与视觉仪式感为基准，输出大师级画面。

**输入**

- 核心创意（一句话灵感或剧情描述）
- 主色调：英雄红（热烈 / 宿命）｜ 影墨黑（水墨 / 隐忍）｜ 竹林绿（清冷 / 杀机）｜ 大漠黄（风沙 / 生命力）
- 节奏类型：慢节奏仪式感长镜 / 中节奏叙事流 / 快节奏蒙太奇（默认慢节奏）
- 运镜倾向：仪式化静止 / 升格慢动作 / 混合模式（默认混合模式）
- 总时长（默认 30 秒）
- 是否提供参考图（人物面容、服装或场景）

仅提供文字描述时，从描述中提炼角色外貌与场景设定写入 spec；提供参考图时先做素材分析再写入 spec。

**交付**：16:9、1080p 成片；跨镜人物、场景、道具、载具关系一致；参考图只作一致性依据，不作成片内容。

## 2. 项目结构规划

- **关键元素分组**：角色、场景、道具、载具各自独立子分组。角色关键元素承载身份板（外貌特征、服装材质与配色、标志性道具、情绪标签），作为全部镜头的身份基准；场景关键元素承载空间类型、主色调统治力、光线特征、标志性固定元素、常驻大自然媒介。
- **序列**：按成片顺序建序列，每个镜头一个生产单元分组。分组描述承载场景引用、故事节拍、景别与构图、镜头运动、大自然媒介、光影与微表情；内部节拍按叙事顺序书写，不按时间码切分。跨镜音频层按生产单元归属记录。
- **资产与素材**：开始提示词草稿、导入或生成时才创建资产。图像资产承载身份板 / 场景板 / 参考图，视频资产承载镜头结果；每个上传、生成、候选、迭代或选定版本都是该资产下的素材。素材不是节点。
- **剪辑**：汇集各镜选定素材，按节奏卡点、转场、音轨合成与淡入淡出完成时间线组装与导出。

## 3. AGENTS.md 策略

- **交付规格**：16:9，1080p（生成后升级，fps 不提升），默认 30 秒，无旁白无字幕。
- **视觉方向**：主色调必须具备画面统治力（占画面 ≥ 65%），非主色调元素降饱和或水墨化处理；保留皮肤毛孔、汗水与尘土、轻微胶片颗粒；严禁大平光、糖水片美颜、过度锐化。
- **节奏与转场**：默认慢节奏仪式感长镜（单镜 6–12 秒，固定长镜占比 ≥ 70%），镜头间默认直切；仪式长镜之间可用 0.5 秒黑场或溶解。严禁滑动、翻页、缩放等现代感转场。
- **模型配置**：角色 / 场景身份板用图像生成（有参考图时改图生图，2K）；分镜视频用视频生成（默认 480p）；环境音与 BGM 用音乐生成。
- **角色与场景身份板**：角色板 16:9 横版、纯白背景、不对称分布、大量留白，含主视觉 / 轮廓研究 / 表情研究 / 细节研究四区块；场景板 16:9 横版、与主色调呼应的纯色背景，含主视觉 / 光影研究 / 细节研究 / 构图框架示意四区块。
- **连戏约束**：同一连续动作或情绪推进的镜头标注同一连戏分组，写明前一镜继承状态、本镜叙事功能、后一镜交接状态。继承状态只记录角色位置、运动速度、环境强度、关键道具状态。

## 4. 创作流程规划

1. **锁定全局参数**：确认输入并写入项目（主色调 / 节奏 / 运镜 / 时长 / 参考图）。
2. **生成镜头结构**：设计角色关键元素（含身份板布局）、场景关键元素、完整分镜列表与跨镜音频层。
3. **生成并确认关键元素参考资产**：为所有关键元素生成或绑定参考图；用户已上传的参考图先注册再绑定。
4. **逐镜生成视频**：所有被引用的关键元素都有确认过的素材后才开始，强制引用对应参考图。
5. **生成音频层**：跨镜环境音或 BGM。
6. **剪辑合成**：用户确认音频层后完成时间线组装、节奏卡点、音画同步。

**依赖顺序**：2→1；3→2；4→3；5→2；6→3,4,5。

**何时暂停**：参数写入后展示 spec 摘要等确认；镜头结构完成后展示分镜与关键元素清单；参考资产生成后展示角色 / 场景 / 道具 / 载具图，缺失或未绑定不得进入视频生成；音频层完成后展示试听或摘要。不得一次性跑完。

**异常与重试**

- **人物一致性失控**：先检查镜头是否正确引用身份板，漏绑则补绑重生成；已绑定仍不一致则切换参考图权重更高的模型重试，最多 2 次；仍失控则向用户说明并请求补充参考图。
- **色彩漂移**：重写提示词时强化主色调权重，并在否定词中追加对应干扰色（`no desaturated red`、`no cool blue cast`）；仍不达标则建议更换参考场景图或改主色调。
- **自然媒介缺失**：在环境段明确提升媒介强度（例如「暴雨砸落的密度极高，水花溅飞至膝盖」）后重新生成。
- **模型失败**：优先在同工具内换模型重试；同工具全部失败则停止并说明，不自动换工具。

## 5. 专业创作方法

**参考图分析**

- 人物：提取性别、年龄感、面部特征（骨骼轮廓、肤色、眼型）、发型发色、服装材质与配色、标志性道具，输出结构化外貌描述并绑定角色关键元素。
- 场景：提取空间类型（殿堂 / 山野 / 竹林 / 大漠）、主色调占比、光线方向与质感、标志性构件，输出结构化场景描述。
- 服装：提取材质（粗麻 / 重工甲胄 / 轻纱）、颜色比例、装饰细节，合并进对应角色描述。

**角色关键元素（身份板）**

每个主要角色必须包含：外貌特征、服装材质与配色（如铁锈红重工甲胄、飞扬宽袖）、标志性道具或配饰、情绪标签（隐忍 / 决绝 / 宿命感）。

板面布局：16:9 横版、纯白背景、不对称、大量留白；① 大型主视觉（全身正面或微侧，展现服装质感）② 轮廓研究区（2–3 个黑色剪影）③ 表情研究区（3–4 个头像特写）④ 细节研究区（衣物纤维、皮肤纹理、手部或佩剑饰物）。

**场景关键元素（场景身份板）**

必须包含：空间类型、主色调统治力（标注占比，建议 ≥ 65%）、光线特征（正侧光 / 强逆光 / 顶光天幕散射；黎明金光 / 正午高反差 / 黄昏长影 / 夜烛火）、标志性固定元素（廊柱、屏风、竹节密度、地平线高度、门洞比例）、常驻大自然媒介。

板面布局：① 大型主视觉（空间纵深 + 标志性构件 + 主色调统治力）② 光影研究区（同场景 2–3 种光线缩略）③ 细节研究区（地面材质、墙体或植被纹理、建筑构件）④ 构图框架示意（标注对称轴线或门洞 / 廊柱 / 竹节间隙）。

**分镜列表**

按节奏规划时长：慢节奏 6–12 秒、固定长镜 ≥ 70%；中节奏 4–8 秒、手持与固定混合；快节奏 2–4 秒，仅用于对决高潮。

每镜必须写：场景引用、故事节拍（拔剑 / 转头 / 合眼等极克制动作与台词）、景别与构图（远景 / 全景 / 中景 / 近景 / 特写 + 对称构图 / 框架构图）、镜头运动（固定 / 缓推 / 缓拉 / 升格 / 手持微晃）、大自然媒介（每镜必须包含并放大一种：狂风 / 暴雨 / 飞雪 / 风沙）、光影（光源方向与明暗层级）、微表情细节（用生理细节描述情绪，禁止「愤怒」「悲伤」等抽象词）。

**跨镜头连续性**

同一奔跑、追逐、对峙、交接或情绪推进的镜头标同一连戏分组，逐镜写明前一镜继承状态、本镜叙事功能、后一镜交接状态。继承状态只记角色位置、运动速度、环境强度、关键道具状态，不复述完整构图。连续动作中的特写或插入镜头必须写出至少 2 个可见连续性证据（载具局部、缰绳鞍具、身体惯性、背景视差、风沙方向、道具摆动频率）。

**跨镜音频层**

默认一条环境音（风声 / 雷雨 / 金属摩擦，与主色调场景匹配）；用户要求时增加一条 BGM（沉郁、宿命感、弦乐主导）；默认无旁白无字幕。

## 6. 张艺谋专属视觉语法

| 维度 | 取值 |
|---|---|
| 主色调 | 英雄红 `#C81D25` / 影墨黑 `#12100F` / 竹林绿 `#2F4F3A` / 大漠黄 `#C89A4B` |
| 色彩统治力 | 主色占画面 ≥ 65%，辅色一律降饱和至 20% 以下或转水墨灰阶 |
| 光线 | 大侧光与强逆光为主，光源单一且方向明确；正午高反差、黄昏长影用于情绪高点 |
| 构图 | 强对称（中轴 / 门洞 / 廊柱）与大面积留白交替；人物常置于画面三分之一并被建筑线条压迫 |
| 运镜 | 固定长镜承载仪式，升格慢动作只给关键动作（落刃、转身、衣袂扬起） |
| 质感 | 布料纤维、甲胄锈迹、汗珠、尘土颗粒必须可见；加轻微胶片颗粒，拒绝塑料皮肤 |
| 禁忌 | 大平光、柔光美颜、多彩杂色、现代运镜（推拉变焦、翻页、缩放） |

**提示词骨架**

```
主体 + 动作（极克制）+ 空间与建筑构件 + 主色调统治（≥65%）+ 单一光源方向与质感
+ 大自然媒介（狂风/暴雨/飞雪/风沙）+ 材质细节（纤维/锈迹/汗尘）+ 胶片颗粒 + 16:9
```

**固定否定词**：`washed-out colors, low contrast flat lighting, beauty filter, plastic skin, oversaturated rainbow palette, modern zoom transition, text watermark`

## 7. Reference 路由

- 需要图像 / 视频生成方式、参考图绑定、分辨率与模型配置、媒体层重试规则 → 读《媒体生成》。
- 撰写身份板或镜头提示词，需要模板结构、视觉锚点顺序、生理细节写法、光影色彩质感词与固定否定词 → 读《提示词写作》。
- 进入剪辑阶段，需要输出规格、节奏卡点、转场规则、音轨合成与分轨音量、淡入淡出时机 → 读《剪辑交付》。
