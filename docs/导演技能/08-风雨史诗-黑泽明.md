# 风雨史诗 · 黑泽明动态美学

> 技能 id：`kurosawa` ｜ 分组：导演风格 ｜ 适用：历史战争、武士题材、灾难叙事、群像史诗
> 落地代码：`src/core/director-styles.mjs` · `src/core/director-skills.mjs`

## 1. 目标、输入与交付

**解决什么问题**：群戏调度混乱、动作看不清、天气只是背景、画面静态无势能。以黑泽明的动态构图与天气叙事为基准，输出有力量、有空间、有戏剧张力的史诗。

**输入**

- 核心创意（一句话灵感或剧情描述）
- 主色调：暴雨灰（默认）｜ 烈焰红 ｜ 泥泞褐 ｜ 雪原白
- 节奏类型：中节奏推进 / 快节奏群戏（默认中节奏推进）
- 运镜倾向：动态跟拍 / 多层景深 + 长焦压缩（默认多层景深）
- 总时长（默认 30 秒）
- 是否提供参考图

**交付**：16:9 成片；群戏中各角色的位置、朝向、旗号与兵器一致；天气与地形必须参与叙事。

## 2. 项目结构规划

- **关键元素分组**：角色（身份板含甲胄形制、旗号纹样、武器）、场景（城寨、荒原、暴雨战场、山道）、道具（旗、枪、弓、火把）、载具（战马、攻城器械）。
- **序列**：按成片顺序，每镜一个生产单元；群戏按"布阵 — 冲撞 — 崩解"的叙事顺序书写。
- **资产与素材**：身份板与场景板为基准；视频资产承载镜头结果。
- **剪辑**：以动作方向与视线引导剪辑，允许动作接动作、多机位覆盖同一次冲撞。

## 3. AGENTS.md 策略

- **交付规格**：16:9，默认 30 秒；台词极少，以群像动作与天气叙事。
- **视觉方向**：高对比黑白灰基底 + 单点色（血、火、旗）；天气（雨、风、尘、雪）必须是画面主体之一，不能只是背景纹理；远景要有纵深层次（前 / 中 / 远三层）。
- **节奏与转场**：中节奏（单镜 4–8 秒），群戏允许 2–4 秒；转场以直切与动作衔接为主，允许视线引导转场；严禁无动机的滑动与缩放。
- **模型配置**：身份板与场景板图像生成；分镜视频偏好动态跟拍与长焦压缩，雨雪强度高。
- **身份板布局**：角色板 16:9，深灰背景，主视觉（全身甲胄）+ 旗号 / 纹样细节 + 表情研究（含雨中怒目）+ 武器细节。
- **连戏约束**：同一场冲撞的全部镜头标同一连戏分组；继承状态只记阵型位置、旗号方向、兵器状态、雨势与地面的泥泞程度。

## 4. 创作流程规划

1. 锁定全局参数（主色 / 节奏 / 运镜 / 时长）。
2. 生成镜头结构（关键元素 + 分镜 + 音频层）。**群戏需先定阵型与运动方向。**
3. 生成并确认关键元素参考资产。
4. 逐镜生成视频（强制绑定身份板与旗号）。
5. 生成音频层（环境雨声 + 鼓点 / 军号）。
6. 剪辑合成（动作方向与视线引导）。

**依赖顺序**：2→1；3→2；4→3；5→2；6→3,4,5。

**何时暂停**：参数摘要、分镜清单、参考资产、音频层四处确认。

**异常与重试**

- **动作看不清**：明确动作方向与身体重心，加入泥浆飞溅、雨水打在甲胄上的反光；否定词追加 `blurry action, unclear motion direction`。
- **群戏混乱**：先锁定阵型图与旗号，再逐镜生成；一次只让一个动作成为视觉主体。
- **天气弱**：把雨 / 风 / 尘写进镜头前半句，并给出强度（"雨柱砸在甲胄上"），重新生成。

## 5. 专业创作方法

**参考图分析**：人物提取甲胄形制（片数、绳结、护肩）、旗号纹样、武器长度；场景提取地形的纵深结构、地平线高度、天气强度。

**角色关键元素**：外貌 + 甲胄形制 + 旗号 / 纹样 + 武器 + 情绪标签（悍勇 / 恐惧 / 决死）。身份板四区块：主视觉、旗号细节、表情研究、武器细节。

**场景关键元素**：空间类型、纵深层次（前 / 中 / 远）、地面材质（泥泞 / 碎石 / 雪）、天气强度、标志性构件。场景板含主视觉 + 光影研究（雨 / 逆光 / 尘）+ 材质细节 + 构图框架示意（阵型轴线与运动方向箭头）。

**分镜列表**

- 中节奏 4–8 秒，群戏 2–4 秒。
- 每镜写：场景、故事节拍（列阵、冲锋、格挡、倒地）、景别与构图（远景给阵型、中景给交锋、特写给身体与武器）、镜头运动（动态跟拍 / 长焦压缩 / 横移）、媒介（暴雨、狂风、尘暴、雪）、光影（阴天散射 + 逆光雨幕）、微表情（雨水顺颌线、指节、喘息）。
- 运动方向必须连续且可读：敌人从画面哪侧进入、主角朝哪个方向推进。

**跨镜连续性**：整场冲撞标同一连戏分组；继承阵型位置、旗号方向、兵器、雨势泥泞。特写必须给出 2 个连续性证据（旗号残破角度、甲片缺失位置、地面泥泞深度、雨滴方向）。

**音频层**：环境音（雨、马蹄、金属撞击）+ BGM（太鼓与低音弦乐）。

## 6. 黑泽明专属视觉语法

| 维度 | 取值 |
|---|---|
| 主色调 | 暴雨灰 `#5A6068` + 泥褐 `#6B5842` / 烈焰红 `#B83227` / 雪原白 `#DCE0E2` |
| 色彩策略 | 低饱和灰基 + 单点高饱和（血、火、旗），对比强烈 |
| 光线 | 阴天散射光 + 逆光雨幕 + 火把点光；允许大面积剪影 |
| 构图 | 三层纵深、对角线动势、群像三角站位、长焦压缩 |
| 运镜 | 动态跟拍、横移、长焦压缩、多机位覆盖同一动作 |
| 质感 | 雨柱、泥浆飞溅、甲胄反光、尘土、旗面湿重 |
| 禁忌 | 模糊动作、动作方向不明、天气仅作背景、扁平群戏 |

**提示词骨架**

```
主体群像 + 明确运动方向 + 三层纵深地形 + 高强度天气（暴雨/尘暴/雪）
+ 阴天散射与逆光雨幕 + 甲胄与旗号细节 + 泥浆飞溅 + 16:9
```

**固定否定词**：`blurry action, unclear motion direction, flat group staging, weak weather, oversaturated color, plastic armor`
