# 花样年华 · 王家卫都市暧昧美学

> 技能 id：`wongkarwai` ｜ 分组：导演风格 ｜ 适用：都市情感、民国上海、暧昧悬疑、品牌情绪片
> 落地代码：`src/core/director-styles.mjs` · `src/core/director-skills.mjs`

## 1. 目标、输入与交付

**解决什么问题**：情绪戏拍成流水账、人物关系没有张力、色彩要么寡淡要么俗艳、镜头语言太"正"没有呼吸感。以王家卫的都市暧昧与时间错位为基准，输出"欲言又止"的电影感。

**输入**

- 核心创意（一句话灵感或剧情描述）
- 主色调：霓虹琥珀（暖黄底 + 洋红点缀，默认）｜ 旗袍绿（深墨绿 + 暗金）｜ 夜雨青（青蓝 + 路灯橙）｜ 旧照褐（褪色棕 + 米白）
- 节奏类型：慢节奏情绪长镜 / 中节奏碎片叙事 / 快节奏抽帧蒙太奇（默认中节奏碎片叙事）
- 运镜倾向：手持微晃 / 抽帧降格 / 混合模式（默认混合模式）
- 总时长（默认 30 秒）
- 是否提供参考图

**交付**：16:9 成片；同一角色跨镜服装、发型、烟与酒杯状态一致；参考图只作一致性依据。

## 2. 项目结构规划

- **关键元素分组**：角色（身份板含服装更换表、香烟 / 酒杯 / 口红等标志物）、场景（走廊、楼梯、车内、雨夜街道、茶餐厅）、道具（怀表、点唱机、未寄出的信）、载具（出租车）。
- **序列**：按成片顺序建序列，每镜一个生产单元；节拍按"相遇 → 错身 → 独白"的叙事顺序，不按时间码切分。
- **资产与素材**：图像资产承载身份板、场景板、参考图；视频资产承载镜头结果。每个候选与迭代版本都是素材。
- **剪辑**：以音乐节拍与抽帧节奏驱动卡点，允许同镜重复、跳切、定格。

## 3. AGENTS.md 策略

- **交付规格**：16:9，默认 30 秒，无旁白；字幕仅允许极短独白（可选单行）。
- **视觉方向**：主色必须有情绪，允许高饱和单色（琥珀黄、洋红、墨绿）与大面积暗部；光斑、雨滴、烟雾、玻璃反射是画面主要质感来源。保留颗粒、轻微失焦与运动拖影；严禁干净棚拍感、均匀平光、无质感的大平光。
- **节奏与转场**：默认中节奏碎片叙事（单镜 3–6 秒），允许抽帧降格、重复镜头、跳切；镜头间多用硬切与同画面内叠化；允许遮挡转场（走过前景、门帘、雨伞）。严禁顺滑的推拉转场。
- **模型配置**：身份板与场景板图像生成（有参考图时图生图）；分镜视频用视频生成，运镜参数偏 handheld + slow shutter。
- **身份板**：角色板突出服装更换（同一角色 2–3 套造型）与手部道具；场景板突出光源位置（霓虹招牌、台灯、车灯）与反光面。
- **连戏约束**：同场景连续镜头必须保持服装、烟酒状态、雨伞开合、时钟时间的连续；跨镜允许时间跳跃但必须由道具状态显式交代。

## 4. 创作流程规划

1. 锁定全局参数（色调 / 节奏 / 运镜 / 时长）。
2. 生成镜头结构（关键元素 + 分镜 + 音频层）。
3. 生成并确认关键元素参考资产。
4. 逐镜生成视频，强制引用身份板。
5. 生成音频层（环境音 + 可选 BGM，BGM 在王家卫风格里权重更高）。
6. 剪辑合成（音乐驱动的卡点与重复）。

**依赖顺序**：2→1；3→2；4→3；5→2；6→3,4,5。

**何时暂停**：参数写入后、镜头结构完成后、参考资产生成后、音频层完成后各暂停一次确认；不得一次跑完。

**异常与重试**

- **人物漂移**：先补绑身份板；仍漂移则加"同一角色同一套服装"权重并重试，最多 2 次。
- **色调失准**：提高单色统治力，否定词追加 `clean white light, flat daylight, corporate commercial look`。
- **氛围缺失**：要求画面内必须出现可见的雨 / 烟 / 霓虹光斑 / 玻璃反射中的至少两项，否则重生成。

## 5. 专业创作方法

**参考图分析**：人物重点提取服装版型（旗袍开衩、西装肩线）、发型定型方式、妆容浓淡；场景重点提取光源色温与招牌文字、墙面材质（马赛克砖、木饰面）、反光面。

**角色关键元素**：外貌 + 服装（含更换表）+ 标志物（烟、酒杯、口红、怀表）+ 情绪标签（隐忍的渴望 / 迟到 / 错过）。身份板布局：16:9，深色背景，左侧全身主视觉，右侧 3 个表情特写（含一次侧脸逆光），底部道具特写条。

**场景关键元素**：空间类型、主色温、光源清单（每盏灯的位置与色温）、反光面、常驻媒介（细雨、烟雾、风）。场景板布局：主视觉 + 3 张不同时段光线缩略 + 材质细节条。

**分镜列表**

- 慢节奏 5–8 秒、中节奏 3–6 秒、快节奏 1.5–3 秒（抽帧）。
- 每镜写：场景、故事节拍（点烟、转身、擦肩、抬眼）、景别与构图（多用框架构图：门框、车窗、镜子）、镜头运动（手持微晃 / 缓推 / 抽帧）、媒介（雨、烟、霓虹光斑）、光影（单光源 + 大面积暗部）、微表情（眼神停留时长、手指停顿、喉结微动）。
- 禁止抽象情绪词，用"视线偏移 3 厘米""烟灰未弹落""手指在杯沿停住"这类生理与动作细节。

**跨镜连续性**：同一次擦肩或同一次等待标同一连戏分组；继承状态只记服装套数、烟酒状态、伞的开合、时钟读数。

**音频层**：环境音（雨声、空调低频、远处爵士乐）；BGM 建议弦乐 + 复古流行改编，情绪克制、循环感强。

## 6. 王家卫专属视觉语法

| 维度 | 取值 |
|---|---|
| 主色调 | 霓虹琥珀 `#D99A3C` + 洋红 `#B23A6B` / 旗袍绿 `#1F3B33` + 暗金 `#C9A227` / 夜雨青 `#1B2A38` + 路灯橙 `#E08A3C` |
| 色彩策略 | 单色统治 + 一点高饱和点缀；暗部保留细节但不提亮 |
| 光线 | 单一实用光源（招牌、台灯、车灯），强反差，允许光斑与眩光 |
| 构图 | 框架构图（门框 / 车窗 / 镜子 / 帘子）、人物偏置、前景遮挡 |
| 运镜 | 手持微晃、慢门拖影、抽帧降格、同镜重复 |
| 质感 | 颗粒、雨滴、烟雾、玻璃反射、胶片褪色 |
| 禁忌 | 均匀棚拍光、干净商业感、完美对称、顺滑推拉转场 |

**提示词骨架**

```
主体 + 克制的动作微差 + 空间（走廊/车内/茶餐厅）+ 单一光源与色温
+ 大面积暗部 + 媒介（细雨/烟雾/霓虹光斑/玻璃反射）+ 胶片颗粒 + 慢门拖影 + 16:9
```

**固定否定词**：`flat studio lighting, clean commercial look, symmetrical composition, smooth zoom transition, oversharpened, plastic skin`
