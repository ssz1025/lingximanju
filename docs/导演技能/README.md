# 导演技能档案索引

十位导演的风格技能档案。每份档案都是一份**可执行的制片策略**：不仅是美学描述，第 6 节的视觉语法表直接对应 `src/core/director-styles.mjs` 里的结构化数据，会真实影响导演阐述、分镜提示词与画面生成。

## 使用方式

1. 打开项目 → 工作台「① 设置基础信息」→ **导演 Agent · 项目技能** → 选择一位导演风格。
2. 选中风格后，卡片下方出现**主色调**色板（每位导演 3–4 个），点色块即切换，无需重选导演。
3. 点「▶ 一键完成最终产物全流程」，导演智能体会按该风格执行导演阐述、分镜、画面与交付验收。
4. 想微调时，改项目「创作设定」里的全局风格串 / 负面串，会与该风格叠加生效。

主色调是风格的正交维度：换色**不改**基调 / 节奏 / 镜头策略 / 声音策略 / 负面词，但会改 `visualStyle`（阐述里的主色与色号）、Mock 出画的 `svg.accent`、真实出图的提示词色号，并触发导演阐述按新主色重写（避免项目里存着过期主色）。换导演一律清空主色，回到新档案的默认色。

## 风格真实生效的四层链路

「选了导演就真的变」不是靠给项目贴标签，而是四层逐一贯通：

| 层 | 落点 | 效果 |
|---|---|---|
| ① 数据 | `src/core/director-styles.mjs` | 十位导演的调色板 / 光线 / 构图 / 运镜 / 媒介 / 禁忌 / 固定否定词，是唯一事实来源 |
| ② 项目状态 | `src/core/project-steps.mjs` → `director-skill` / `director-palette` | `management.director.styleId` + `paletteKey` 持久化；换导演清主色、切主色校验色号白名单 |
| ③ 项目级解析 | `resolveProjectAesthetic(project)` | 合成生效中的美学对象（含 `svg`），下发为 `settings.aesthetic` |
| ④ 生成侧消费 | `providers.stylePrompts` / `mockPalette` / `aestheticTreatment` / `aestheticShotSuffix` | 真实模型拿正向风格串 + 固定否定词；Mock 出画按主色换 `accent`；分镜的 `ffDesc` / `motionDesc` / `audioDesc` 带主色、光线与媒介声源 |

关键约束：Mock 模板产物必须自报 `__mockKeys`，否则 `director-agent` 会误以为拿到了 LLM 输出而跳过风格基线；零 Key 下风格基线优先于通用模板，模板只能补 `title` / `logline`。这三点由 `tests/director-provider.test.mjs` 锁住。

## 四份流程策略（不含美学）

除十位导演风格外，工作台还保留四个与画面美学无关的**流程策略**技能，用于控制交付物与步骤范围。工作台面板按 `group` 分成「制片流程策略」与「导演风格」两栏，共 **4 + 10 = 14 个可选技能**：

| id | 名称 | 用途 |
|---|---|---|
| `full` | 全流程导演 | 六步全跑，双产物（成片 + 导演包） |
| `script` | 剧本精修导演 | 先补创作设定，再六步全跑 |
| `visual` | 视觉一致性导演 | 只跑智能体四步，强制按画布重打包 |
| `pack` | 交接包导演 | 只产出导演包，跳过本地视频渲染 |

风格技能一律走「完整六步 + 沿用项目交付设置」，只改变美学、不改交付组合；流程策略一律 `styleId = null`，不注入任何美学。两者互斥选择，任一时刻只有一个是生效的。

## 每份档案的统一结构

1. **目标、输入与交付** —— 解决什么痛点、需要哪些输入、交付什么
2. **项目结构规划** —— 关键元素分组 / 序列 / 资产与素材 / 剪辑
3. **AGENTS.md 策略** —— 交付规格、视觉方向、节奏与转场、模型配置、身份板布局、连戏约束
4. **创作流程规划** —— 六步流程、依赖顺序、暂停点、异常与重试
5. **专业创作方法** —— 参考图分析、角色 / 场景关键元素、分镜列表、跨镜连续性、音频层
6. **导演专属视觉语法** —— 调色板、光线、构图、运镜、质感、禁忌、提示词骨架、固定否定词
7. **Reference 路由** —— 何时读媒体生成 / 提示词写作 / 剪辑交付
8. **代码落地映射** —— 该风格在本项目里落到哪些文件与函数
