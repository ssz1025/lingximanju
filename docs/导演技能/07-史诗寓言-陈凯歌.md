# 史诗寓言 · 陈凯歌人文美学

> 技能 id：`chen-kaige` ｜ 分组：导演风格 ｜ 适用：历史史诗、戏曲题材、寓言式叙事、文化寻根
> 落地代码：`src/core/director-styles.mjs` · `src/core/director-skills.mjs`

## 1. 目标、输入与交付

**解决什么问题**：历史题材拍成cosplay、宏大场景没有精神内核、台词像解说、舞台感与电影感失衡。以陈凯歌的史诗构图与寓言气质为基准，输出有精神重量的影像。

**输入**

- 核心创意（一句话灵感或剧情描述）
- 主色调：宫廷绛（默认）｜ 戏台金 ｜ 荒原褐 ｜ 雪夜蓝
- 节奏类型：慢节奏仪式段落 / 中节奏叙事（默认慢节奏仪式段落）
- 运镜倾向：仪式化固定 / 缓慢升降 / 混合（默认混合）
- 总时长（默认 30 秒）
- 是否提供参考图

**交付**：16:9 成片；同一角色的戏服、妆面、道具（剑、琵琶、面具）跨镜一致；宏大场面必须有可读的人物关系。

## 2. 项目结构规划

- **关键元素分组**：角色（身份板含戏服 / 官服形制、妆面、身份标识）、场景（宫廷、戏台、荒原、雪原、长阶）、道具（剑、琵琶、面具、诏书）、载具（战车、仪仗）。
- **序列**：按成片顺序，每镜一个生产单元；节拍按"仪式 — 撕裂 — 回望"的叙事顺序书写。
- **资产与素材**：身份板与场景板为基准；视频资产承载镜头结果。
- **剪辑**：仪式段用长镜与固定画面，撕裂段用短切与声画对位，结尾用静止画面收束。

## 3. AGENTS.md 策略

- **交付规格**：16:9，默认 30 秒；允许文学性台词（短，最多 2 句），无旁白。
- **视觉方向**：强对比、重色彩、舞台化的光（顶光、追光、烛阵），但必须有真实材质支撑（丝绸反光、甲胄锈迹、雪地颗粒）；画面要"有戏"，即构图本身讲述矛盾。
- **节奏与转场**：慢节奏仪式（单镜 6–12 秒）与中节奏叙事交替；转场允许溶解与黑场，禁止炫技。
- **模型配置**：身份板与场景板图像生成（有参考图时图生图）；分镜视频运动克制，舞台段允许缓慢升降。
- **身份板布局**：角色板 16:9，深绛背景，主视觉（全身戏服 / 官服）+ 妆面研究（3 个）+ 身份标识细节（冠、佩、纹章）+ 姿态研究（行礼、跪拜、持械）。
- **连戏约束**：同一场仪式、同一段长阶行进标同一连戏分组；继承状态只记人物在队列中的位置、妆面是否已卸、道具状态、场景光源（烛阵 / 顶光）。

## 4. 创作流程规划

1. 锁定全局参数（主色 / 节奏 / 运镜 / 时长）。
2. 生成镜头结构（关键元素 + 分镜 + 音频层）。
3. 生成并确认关键元素参考资产。
4. 逐镜生成视频（强制绑定身份板与妆面）。
5. 生成音频层（环境音 + 戏曲或交响 BGM）。
6. 剪辑合成（声画对位与仪式收束）。

**依赖顺序**：2→1；3→2；4→3；5→2；6→3,4,5。

**何时暂停**：参数摘要、分镜清单、参考资产、音频层四处确认。

**异常与重试**

- **舞台感过头**：加强真实材质与空气感（雪粒、烛烟、丝绸反光），否定词追加 `theatrical backdrop, painted set, cardboard props`。
- **内核空**：重写故事节拍，让构图承载矛盾（例如"跪着的人与站着的队列"），而不是靠台词说明。
- **人物漂移**：补绑身份板与妆面参考后重试，最多 2 次。

## 5. 专业创作方法

**参考图分析**：人物提取戏服 / 官服形制（层数、纹样、配饰）、妆面（眉眼、髯口、花钿）、身份标识；场景提取建筑比例与仪式轴线、光源布置（烛阵 / 顶光 / 追光）。

**角色关键元素**：外貌 + 戏服 / 官服形制 + 妆面 + 身份标识 + 情绪标签（孤高 / 悲怆 / 执念）。身份板四区块：主视觉、妆面研究、身份标识、姿态研究。

**场景关键元素**：空间类型（宫廷 / 戏台 / 荒原 / 长阶）、建筑比例与轴线、光源布置、标志性构件、常驻媒介（雪、烟、烛火）。场景板含主视觉 + 光影研究 + 材质细节 + 构图框架示意（仪式轴线与门洞）。

**分镜列表**

- 慢节奏 6–12 秒，中节奏 4–8 秒。
- 每镜写：场景、故事节拍（登阶、跪拜、击鼓、拔剑、回望）、景别与构图（远景给场面、中景给关系、特写给妆面与手）、镜头运动（固定 / 缓升 / 缓降）、媒介（雪、烟、烛火、风沙）、光影（顶光、追光、烛阵）、微表情（眼神、唇线、手指颤动）。
- 构图必须承担叙事：权力高低用机位与体量对比，孤立用留白与轴线偏移。

**跨镜连续性**：同一场仪式、同一段行进标同一连戏分组；继承位置、妆面状态、道具、光源。特写必须给出 2 个连续性证据（妆面裂纹、甲胄血迹、雪落在肩、道具缺口）。

**音频层**：环境音（风、雪、脚步、鼓）+ BGM（戏曲锣鼓或交响，强调宿命感）。

## 6. 陈凯歌专属视觉语法

| 维度 | 取值 |
|---|---|
| 主色调 | 宫廷绛 `#7A1E28` + 金 `#C9A227` / 戏台金 `#D9A441` / 荒原褐 `#8B6B4A` |
| 色彩策略 | 重色块 + 单点高光（金、烛、血色），非主色压暗 |
| 光线 | 舞台化光源（顶光、追光、烛阵）+ 真实大气散射，形成双重层次 |
| 构图 | 强轴线、体量对比、留白；画面本身讲述权力与孤独 |
| 运镜 | 仪式化固定、缓慢升降、长镜跟随队列 |
| 质感 | 丝绸反光、甲胄锈迹、雪地颗粒、烛烟 |
| 禁忌 | 舞台布景感、纸板道具、解说式台词、炫技转场 |

**提示词骨架**

```
主体 + 仪式动作 + 建筑比例与仪式轴线 + 舞台化光源（顶光/追光/烛阵）
+ 真实材质（丝绸/锈甲/雪粒）+ 体量对比构图 + 16:9
```

**固定否定词**：`theatrical backdrop, painted set, cardboard props, flat lighting, oversaturated rainbow, plastic texture`
