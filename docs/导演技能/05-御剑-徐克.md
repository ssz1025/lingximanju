# 御剑 · 徐克武侠奇诡美学

> 技能 id：`tsui-hark` ｜ 分组：导演风格 ｜ 适用：武侠奇幻、江湖对决、东方魔幻、游戏 CG 短片
> 落地代码：`src/core/director-styles.mjs` · `src/core/director-skills.mjs`

## 1. 目标、输入与交付

**解决什么问题**：打戏软绵绵、特效像贴图、动作没有空间逻辑、奇观镜头廉价。以徐克的高动能武侠与奇诡视觉为基准，输出腾挪有度、奇观可信的江湖。

**输入**

- 核心创意（一句话灵感或剧情描述）
- 主色调：玄冰蓝（冷月 / 剑光，默认）｜ 烈火橙 ｜ 妖紫 ｜ 血墨红
- 节奏类型：快节奏对决 / 中节奏张力推进（默认中节奏张力推进）
- 运镜倾向：高速跟拍 / 升格 + 甩镜 / 混合模式（默认混合模式）
- 总时长（默认 30 秒）
- 是否提供参考图

**交付**：16:9 成片；同一场对决的兵器、衣袂、地形与速度关系连续；奇观元素必须与人物动作有因果。

## 2. 项目结构规划

- **关键元素分组**：角色（身份板含兵器、武功门派视觉特征、衣袂动势）、场景（崖顶、古寺、竹林、冰湖、客栈）、道具（刀剑、暗器、机关、符箓）、载具（飞舟、纸鸢、神兽坐骑）。
- **序列**：按成片顺序，每镜一个生产单元；对决段落按"起势 — 交锋 — 转折"叙事顺序书写。
- **资产与素材**：身份板与场景板为基准；视频资产承载镜头结果；每个迭代版本都是素材。
- **剪辑**：以动作节拍与音乐重音卡点，允许升格强调关键一击、甩镜连接空间。

## 3. AGENTS.md 策略

- **交付规格**：16:9，默认 30 秒；无旁白，允许极短喝声与台词。
- **视觉方向**：高对比、冷月或烈火主导；光效必须有来源（剑光、符火、月华、水波反射）；衣袂、水花、碎冰、火星是动态质感核心；严禁糊成一团的粒子特效和没有方向的光晕。
- **节奏与转场**：中节奏（单镜 3–6 秒）为主，对决高潮允许 2–4 秒快切；升格只给决定胜负的那一击；转场可用甩镜、动作接动作、遮挡切入；严禁无动机的翻页与缩放。
- **模型配置**：身份板与场景板图像生成（有参考图时图生图）；分镜视频偏高运动强度，允许 motion blur。
- **身份板布局**：角色板 16:9，深色背景，主视觉（全身含兵器）+ 轮廓研究（持械姿态 3 个）+ 表情研究（含怒目与冷静）+ 兵器细节区。
- **连戏约束**：同一场对决的全部镜头标同一连戏分组；继承状态只记双方站位、兵器是否出鞘 / 脱手、地形破坏程度、速度与方向。

## 4. 创作流程规划

1. 锁定全局参数（主色 / 节奏 / 运镜 / 时长）。
2. 生成镜头结构（关键元素 + 分镜 + 音频层）。
3. 生成并确认关键元素参考资产。
4. 逐镜生成视频（强制绑定身份板与兵器）。
5. 生成音频层（环境音 + 打击乐 / 金属摩擦）。
6. 剪辑合成（卡点与升格）。

**依赖顺序**：2→1；3→2；4→3；5→2；6→3,4,5。

**何时暂停**：参数摘要、分镜清单、参考资产、音频层四处确认。

**异常与重试**

- **动作软**：提高运动强度，加入速度线、衣袂扬起、落地扬尘，否定词追加 `stiff motion, weightless fighting`。
- **特效糊**：要求光效有明确光源与形状（剑光成线、符火成环），否定词追加 `mushy particle effect, random glow`。
- **人物漂移**：补绑身份板与兵器参考后重试，最多 2 次。

## 5. 专业创作方法

**参考图分析**：人物提取兵器形制（刀身弧度、护手）、门派服饰特征（绣纹、束带、披风）、衣袂长度；场景提取地形高差、光源位置、可破坏构件。

**角色关键元素**：外貌 + 门派服饰 + 兵器（形制与光效）+ 武功视觉特征（出招时的轨迹）+ 情绪标签（凌厉 / 桀骜 / 悲怆）。身份板四区块：主视觉、持械姿态、表情研究、兵器细节。

**场景关键元素**：空间类型、地形高差与可运动路径、光源（月光 / 火光 / 水光）、标志性构件、常驻媒介（风、水雾、火星）。场景板含主视觉 + 光影研究 + 材质细节 + 构图框架示意（决斗轴线）。

**分镜列表**

- 中节奏 3–6 秒，高潮 2–4 秒；升格仅用于关键一击。
- 每镜写：场景、故事节拍（拔剑、腾跃、格挡、落刃）、景别与构图（全景交代空间、中近景给交锋、特写给兵器与眼神）、镜头运动（高速跟拍 / 甩镜 / 升格）、媒介（狂风、水雾、火星、碎冰）、光影（冷月逆光 / 火光侧打）、微表情（瞳孔收缩、指节发白、呼吸起伏）。
- 打斗必须有空间逻辑：谁在哪、朝向哪、兵器相交点在哪。

**跨镜连续性**：整场对决标同一连戏分组；继承状态记站位、兵器状态、地形破坏、运动方向与速度。连续动作中的特写必须写出 2 个可见连续性证据（兵器缺口、衣袂破损、地面裂痕、速度线方向）。

**音频层**：环境音（风声、金属摩擦、脚步与落地）+ BGM（鼓点与弦乐，重音与出招同步）。

## 6. 徐克专属视觉语法

| 维度 | 取值 |
|---|---|
| 主色调 | 玄冰蓝 `#1F3B5C` + 月白 `#DCE8F2` / 烈火橙 `#E2571F` / 妖紫 `#6B3E86` |
| 色彩策略 | 双色对比（冷月 / 烈火），光效高亮但不泛白 |
| 光线 | 有明确来源的强光（月华、符火、水波反射、剑光），允许逆光剪影 |
| 构图 | 对角线动势、前后景分层（前景衣袂 / 中景交锋 / 远景奇观）、决斗轴线明确 |
| 运镜 | 高速跟拍、甩镜、升格、俯冲；运动方向必须连贯 |
| 质感 | 衣袂、水花、碎冰、火星、金属反光；允许 motion blur |
| 禁忌 | 软绵绵动作、糊成团的粒子、无来源光晕、贴图感特效 |

**提示词骨架**

```
主体 + 出招动作 + 空间高差与地形 + 有来源的强光方向（月华/符火/剑光）
+ 兵器形制与相交点 + 动态质感（衣袂/水花/火星/碎冰）+ motion blur + 16:9
```

**固定否定词**：`stiff motion, weightless fighting, mushy particle effect, random glow, flat lighting, plastic armor`
