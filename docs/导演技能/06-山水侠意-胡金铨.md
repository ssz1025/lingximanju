# 山水侠意 · 胡金铨客栈美学

> 技能 id：`king-hu` ｜ 分组：导演风格 ｜ 适用：古典武侠、客栈对峙、禅意山水、戏曲化动作片
> 落地代码：`src/core/director-styles.mjs` · `src/core/director-skills.mjs`

## 1. 目标、输入与交付

**解决什么问题**：古装戏像现代剧、节奏拖沓、动作没有韵律、空间像棚拍。以胡金铨的客栈空间、戏曲节奏与山水留白为基准，输出有古意、有韵律的武侠。

**输入**

- 核心创意（一句话灵感或剧情描述）
- 主色调：水墨灰（默认）｜ 古寺赭 ｜ 松林墨绿 ｜ 暮色金
- 节奏类型：慢起 — 骤急（长段铺陈 + 短促爆发，默认慢起骤急）
- 运镜倾向：固定机位 + 精准横移 / 快速剪切（默认固定 + 横移）
- 总时长（默认 30 秒）
- 是否提供参考图

**交付**：16:9 成片；同一客栈的空间结构（楼层、门洞、楼梯位置）严格一致；动作有戏曲韵律。

## 2. 项目结构规划

- **关键元素分组**：角色（身份板含服饰纹样、兵器、身段）、场景（客栈内外、山道、竹林、古寺）、道具（灯笼、桌椅、兵器架、经卷）、载具（马车、轿）。
- **序列**：按成片顺序，每镜一个生产单元；节拍以"铺垫 — 逼近 — 爆发"的叙事顺序书写。
- **资产与素材**：场景板必须锁定客栈平面结构，作为全片空间基准；视频资产承载镜头结果。
- **剪辑**：铺垫段用长镜，对峙与爆发用精准短切；剪辑点落在动作启动的瞬间，制造"骤急"。

## 3. AGENTS.md 策略

- **交付规格**：16:9，默认 30 秒；台词极少，以环境声与动作节奏叙事。
- **视觉方向**：水墨灰调、层次分明、烟雾与灯笼光作氛围；木构质感（木纹、榫卯、旧漆）必须可辨；服饰纹样清晰但不花哨。
- **节奏与转场**：铺垫段单镜 6–10 秒，爆发段 1–2 秒，形成强烈的节奏落差；转场以直切与遮挡为主；严禁匀速节奏。
- **模型配置**：身份板与场景板图像生成；分镜视频运动精准克制，爆发段允许快速剪切。
- **身份板布局**：角色板 16:9，米白背景，主视觉（全身，含身段）+ 轮廓研究（3 个剪影：持械 / 行礼 / 腾跃）+ 表情研究（3 个）+ 服饰纹样细节区。
- **连戏约束**：客栈内的所有镜头标同一连戏分组；继承状态只记人物所在楼层与门洞、灯笼是否点亮、兵器是否在手、桌椅位移。

## 4. 创作流程规划

1. 锁定全局参数（主色 / 节奏 / 运镜 / 时长）。
2. 生成镜头结构（关键元素 + 分镜 + 音频层）。**场景板必须先定客栈平面结构。**
3. 生成并确认关键元素参考资产。
4. 逐镜生成视频（强制绑定场景板，保证空间一致）。
5. 生成音频层（环境音 + 戏曲打击乐）。
6. 剪辑合成（节奏落差与卡点）。

**依赖顺序**：2→1；3→2；4→3；5→2；6→3,4,5。

**何时暂停**：参数摘要、分镜清单、参考资产、音频层四处确认。

**异常与重试**

- **节奏平**：重排分镜时长，把铺垫段拉长、爆发段压到 1–2 秒，否定词追加 `even pacing, no rhythm contrast`。
- **空间乱**：以场景板的客栈结构重写镜头的机位与门洞朝向，重新生成。
- **人物漂移**：补绑身份板重试，最多 2 次。

## 5. 专业创作方法

**参考图分析**：人物提取服饰纹样（云纹、回纹）、兵器形制、身段姿态；场景提取木构结构（梁柱、楼梯、门洞比例）、灯笼位置、雾气浓度。

**角色关键元素**：外貌 + 服饰纹样 + 兵器 + 身段特征（步伐、手势、行礼方式）+ 情绪标签（沉静 / 决绝 / 悲悯）。身份板四区块：主视觉、轮廓研究、表情研究、纹样细节。

**场景关键元素**：空间类型（客栈 / 山道 / 古寺）、木构结构与门洞比例、光源（灯笼 / 月光 / 香火）、标志性固定元素、常驻媒介（雾、尘、风）。场景板含主视觉 + 光影研究 + 木构细节 + 构图框架示意（门洞与楼梯轴线）。

**分镜列表**

- 铺垫段 6–10 秒，爆发段 1–2 秒。
- 每镜写：场景、故事节拍（推门、上楼、落座、拍桌、出剑）、景别与构图（框架构图：门洞、楼梯、窗格；对称构图给对峙）、镜头运动（固定 / 精准横移 / 快速剪切）、媒介（雾、尘、灯笼光晕）、光影（灯笼暖光 + 月光冷光对比）、微表情（眼神、手指、呼吸）。
- 动作必须有戏曲韵律：起势、停顿、出手三段式。

**跨镜连续性**：整场客栈戏标同一连戏分组；继承状态记楼层、门洞、灯笼、兵器、桌椅位移。爆发段特写需写出 2 个连续性证据（灯笼摆动、桌上酒碗位置、兵器缺口、楼梯第三阶的破损）。

**音频层**：环境音（木门吱呀、脚步、风声、雾中的虫鸣）+ BGM（锣鼓与梆子，节奏与动作卡点）。

## 6. 胡金铨专属视觉语法

| 维度 | 取值 |
|---|---|
| 主色调 | 水墨灰 `#6B6F72` + 米白 `#E8E3D8` / 古寺赭 `#8C5A3C` / 松林墨绿 `#38473C` |
| 色彩策略 | 灰调为主，暖光（灯笼）与冷光（月光）双色对比 |
| 光线 | 灯笼暖光作点光、月光作环境光、雾气散射；明暗层次分明 |
| 构图 | 框架构图（门洞 / 窗格 / 楼梯）、对称对峙、留白与雾气填充 |
| 运镜 | 固定机位、精准横移、爆发段快速剪切 |
| 质感 | 木纹与榫卯、旧漆、织纹、雾气颗粒 |
| 禁忌 | 现代服饰感、匀速节奏、棚拍平光、无韵律打斗 |

**提示词骨架**

```
主体 + 戏曲化动作（起势/停顿/出手）+ 木构空间与门洞比例 + 灯笼暖光与月光冷光
+ 雾气颗粒 + 服饰纹样与木纹质感 + 框架构图 + 16:9
```

**固定否定词**：`modern costume, even pacing, studio flat lighting, rhythmless fighting, oversaturated color, plastic texture`

## 7. Reference 路由
