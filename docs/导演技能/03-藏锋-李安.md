# 藏锋 · 李安东方克制美学

> 技能 id：`ang-lee` ｜ 分组：导演风格 ｜ 适用：东方家庭伦理、武侠留白、跨文化题材、文艺长片
> 落地代码：`src/core/director-styles.mjs` · `src/core/director-skills.mjs`

## 1. 目标、输入与交付

**解决什么问题**：情绪外放表演化、冲突靠喊、画面漂亮但没有潜台词、文化质感靠堆符号。以李安的克制与"水面下的张力"为基准，输出含蓄而有重量的电影。

**输入**

- 核心创意（一句话灵感或剧情描述）
- 主色调：素雅青灰（默认）｜ 竹林墨绿 ｜ 家宴暖褐 ｜ 雪山冷白
- 节奏类型：慢节奏静观长镜 / 中节奏递进（默认慢节奏静观长镜）
- 运镜倾向：固定机位为主 / 缓慢横移（默认固定为主）
- 总时长（默认 30 秒）
- 是否提供参考图

**交付**：16:9 成片；角色服饰、餐桌布置、家庭空间一致；克制表达，不靠台词说明一切。

## 2. 项目结构规划

- **关键元素分组**：角色（身份板含礼仪姿态、服饰层级、手部动作）、场景（厅堂、饭桌、竹林、山道）、道具（碗筷、书信、剑、家宴菜肴）、载具（马车、渡船）。
- **序列**：按成片顺序，每镜一个生产单元。节拍按"压抑 → 决口 → 复归"的叙事顺序书写。
- **资产与素材**：身份板与场景板作为跨镜基准；视频资产承载镜头结果。
- **剪辑**：以静接静，允许长镜内完成情绪转折；转场多用直切与留白式黑场。

## 3. AGENTS.md 策略

- **交付规格**：16:9，默认 30 秒；允许极少的低声台词，禁止旁白解说情绪。
- **视觉方向**：低饱和、自然光、柔和但层次分明；肤色真实（可见毛孔与疲惫感），避免糖水美颜；环境细节（器物质感、织物褶皱、桌面水渍）必须可辨。
- **节奏与转场**：慢节奏静观（单镜 6–10 秒），固定机位占比 ≥ 70%；镜头间默认直切，允许 0.5 秒黑场留白；严禁炫技运镜与花哨转场。
- **模型配置**：身份板与场景板图像生成（有参考图时图生图）；分镜视频用视频生成，运动强度低。
- **身份板布局**：角色板 16:9，浅灰背景，主视觉（全身，含礼仪姿态）+ 3 个表情特写（含一次低头 / 侧目）+ 手部细节条（执筷、握剑、递物）+ 服饰层级示意。
- **连戏约束**：同一场家宴 / 同一段山路的镜头标同一连戏分组；继承状态只记坐次位置、菜色推进、衣襟与袖口的状态、道具（剑是否出鞘）。

## 4. 创作流程规划

1. 锁定全局参数（主色 / 节奏 / 运镜 / 时长）。
2. 生成镜头结构（关键元素 + 分镜 + 音频层）。
3. 生成并确认关键元素参考资产。
4. 逐镜生成视频（强制绑定身份板）。
5. 生成音频层（环境音为主，BGM 极简）。
6. 剪辑合成。

**依赖顺序**：2→1；3→2；4→3；5→2；6→3,4,5。

**何时暂停**：参数摘要、分镜清单、参考资产、音频层四处暂停确认。

**异常与重试**

- **表演过火**：把动作改写为"最小可行动作"（手指收紧、视线下移半寸），否定词追加 `exaggerated acting, theatrical gesture`。
- **画面寡淡**：不是提高饱和度，而是加强光线层次与环境细节（窗棂投影、桌面反光）后重生成。
- **人物漂移**：补绑身份板后重试，最多 2 次。

## 5. 专业创作方法

**参考图分析**：人物重点提取服饰层级（里衣 / 外袍 / 配饰）与姿态习惯；场景重点提取自然光源方向（窗、门、天井）、器物摆放与空间仪式感。

**角色关键元素**：外貌 + 服饰层级 + 姿态习惯（坐姿、行礼、执物手）+ 情绪标签（压抑 / 退让 / 决意）。身份板四区块：主视觉、表情研究、手部细节、服饰层级示意。

**场景关键元素**：空间类型（厅堂 / 竹林 / 山道）、自然光源与时段、标志性构件（门楣、屏风、竹节密度）、常驻媒介（微风、薄雾、落叶）。场景板含主视觉 + 光影研究 + 器物细节 + 构图框架示意（对称轴线）。

**分镜列表**

- 慢节奏 6–10 秒，中节奏 4–7 秒。固定机位为主，允许极缓慢横移。
- 每镜写：场景、故事节拍（放下筷子、起身、行礼、收剑）、景别与构图（中景 / 全景 + 对称构图为主）、镜头运动（固定 / 极缓横移）、媒介（微风、薄雾、落叶）、光影（自然窗光、柔和但有方向）、微表情（喉头一动、睫毛下垂、指尖停在半空）。
- 禁止"愤怒""悲伤"，用身体细节替代。

**跨镜连续性**：同一次家宴、同一次送别标同一连戏分组，继承坐次、菜色、服饰状态、关键道具位置。

**音频层**：环境音以室内细节为主（碗筷轻碰、布料摩擦、远处水声）；BGM 极简，可用单一弦乐或留白。

## 6. 李安专属视觉语法

| 维度 | 取值 |
|---|---|
| 主色调 | 素雅青灰 `#8A9A9E` + 米白 `#EDE6D8` / 竹林墨绿 `#3C5144` / 家宴暖褐 `#A9714B` |
| 色彩策略 | 低饱和、自然色温，靠光线层次而非色块制造情绪 |
| 光线 | 自然窗光与天井光，方向明确但柔和；室内灯只作补光 |
| 构图 | 对称、稳定、留白；人物与器物并置，强调空间里的"礼" |
| 运镜 | 固定长镜、极缓慢横移；几乎不用变焦 |
| 质感 | 真实肤色（毛孔 / 疲惫）、织物褶皱、器物釉面与水渍 |
| 禁忌 | 高饱和、糖水美颜、炫技运镜、夸张表演、符号堆砌 |

**提示词骨架**

```
主体 + 最小可行动作 + 空间与自然光源方向 + 低饱和自然色温
+ 器物与织物细节（釉面/褶皱/水渍）+ 柔和层次 + 16:9
```

**固定否定词**：`high saturation, beauty filter, exaggerated acting, theatrical gesture, flashy camera move, plastic skin, oversharpened`
